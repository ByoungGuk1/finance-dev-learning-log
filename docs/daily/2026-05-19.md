## 2. main 메서드의 매개변수

Java 프로그램의 시작점은 `main()` 메서드이다.

```java
public static void main(String[] args) {
}
```

`String[] args`는 프로그램 실행 시 외부에서 전달받는 값이다.

예를 들어 커맨드 창에서 다음처럼 실행하면:

```bash
java CommandParameter 100 200
```

`args`에는 다음 값이 들어간다.

```java
args[0] // "100"
args[1] // "200"
```

명령행 매개변수는 문자열로 들어오기 때문에 숫자로 계산하려면 형 변환이 필요하다.

```java
int num1 = Integer.parseInt(args[0]);
int num2 = Integer.parseInt(args[1]);
```

주의할 점:

- `args`는 문자열 배열이다.
- 숫자로 사용하려면 `Integer.parseInt()` 같은 변환 메서드가 필요하다.
- 인자가 부족한 상태에서 `args[0]`, `args[1]`을 바로 사용하면 오류가 발생한다.

## 3. Eclipse에서 Program Arguments 설정

Eclipse에서도 실행 시 `main()` 메서드의 `args`에 값을 넣을 수 있다.

설정 흐름:

```text
클래스 우클릭
→ Run As
→ Run Configurations
→ 실행할 클래스 선택
→ Arguments 탭
→ Program arguments 입력
→ Run
```

예를 들어 Program arguments에 다음 값을 입력하면:

```text
100 200
```

`main(String[] args)`에서는 다음처럼 받을 수 있다.

```java
args[0] // "100"
args[1] // "200"
```

정리:

- Eclipse Run Configurations에 설정한 값은 Eclipse 실행 환경에서만 유지된다.
- 커맨드 창에서 직접 실행할 때는 별도로 인자를 입력해야 한다.
- 즉, Eclipse에서 설정한 Program arguments가 커맨드 창 실행에 자동 적용되는 것은 아니다.

## 4. command line arguments 실습

명령행 매개변수로 두 정수를 입력받아 사칙연산을 수행할 수 있다.

```java
public class CommandParameter {
    public static void main(String[] args) {
        if (args.length != 2) {
            System.err.println("명령행 매개변수는 2개 필요합니다.");
            return;
        }

        try {
            int num1 = Integer.parseInt(args[0]);
            int num2 = Integer.parseInt(args[1]);

            System.out.println("덧셈 : " + (num1 + num2));
            System.out.println("뺄셈 : " + (num1 - num2));
            System.out.println("곱셈 : " + num1 * num2);
            System.out.println("몫 : " + num1 / num2);
            System.out.println("나머지 : " + num1 % num2);
        } catch (NumberFormatException e) {
            System.err.println("정수를 입력해야 합니다.");
        } catch (ArithmeticException e) {
            System.err.println("0으로 나눌 수 없습니다.");
        }
    }
}
```

예외처리:

- 문자열을 숫자로 바꿀 때 `NumberFormatException`이 발생할 수 있다.
- 나눗셈에서는 0으로 나누는 경우도 고려해야 한다.

## 5. 상수와 enum

상수는 한 번 값을 정하면 변경할 수 없는 값이다.

```java
static final String SUCCESS = "성공";
static final int MAX_VALUE = 90;
```

상수만 사용할 수도 있지만, 정해진 값의 집합을 표현할 때는 `enum`이 더 적합하다.

```java
enum Week {
    MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY
}
```

## 5-1. enum을 사용하는 이유

`enum`은 사용할 수 있는 값을 제한한다.

```java
Week today = Week.TUESDAY;

// today = "TUESDAY"; // 컴파일 오류
```

문자열 상수는 잘못된 값이 들어와도 컴파일 시점에 막기 어렵다.

```java
String today = "TUESDAY";
today = "ABC"; // 문법상 가능
```

반면 `enum`은 정해진 값만 사용할 수 있기 때문에 실수를 줄일 수 있다.

정리:

| 방식                | 특징                                       |
| ------------------- | ------------------------------------------ |
| `static final` 상수 | 단순한 고정값에 적합                       |
| `enum`              | 정해진 값의 집합을 타입으로 표현할 때 적합 |

## 6. enum 주요 메서드

`enum`은 내부적으로 클래스처럼 동작하며, 몇 가지 메서드를 제공한다.

```java
Week[] arr = Week.values();

for (Week day : arr) {
    System.out.println(day.name());
    System.out.println(day.ordinal());
}
```

| 메서드      | 의미                                |
| ----------- | ----------------------------------- |
| `values()`  | enum에 정의된 모든 값을 배열로 반환 |
| `name()`    | enum 상수 이름을 문자열로 반환      |
| `ordinal()` | enum 상수가 선언된 순서를 반환      |

주의할 점:

```java
switch (today.ordinal()) {
}
```

`ordinal()`을 기준으로 `switch`문을 사용할 수도 있지만, enum 순서가 바뀌면 코드 의미도 같이 바뀔 수 있다.
가능하면 enum 값 자체로 `switch`를 작성하는 편이 낫다.

```java
switch (today) {
    case MONDAY -> System.out.println("월요일");
    case TUESDAY -> System.out.println("화요일");
    default -> System.out.println("기타 요일");
}
```

## 7. 메모리 구조와 참조 변수

Java 메모리는 크게 3가지로 나누어 이해할 수 있다.

| 영역        | 저장 내용                              |
| ----------- | -------------------------------------- |
| 메서드 영역 | 클래스 정보, static 관련 정보, 상수 등 |
| 스택 영역   | 메서드 호출 정보, 지역 변수, 참조 변수 |
| 힙 영역     | `new`로 생성된 객체와 배열             |

참조 변수는 스택 영역에 만들어지고, `new`로 생성한 객체는 힙 영역에 만들어진다.

```java
Car c1 = new Car();
```

위 코드는 다음 흐름으로 이해할 수 있다.

```text
1. 스택 영역에 참조 변수 c1 생성
2. 힙 영역에 Car 객체 생성
3. c1이 힙 영역의 Car 객체를 참조
```

스택에 객체를 가리키는 참조값이 저장된다.

## 8. 클래스, 객체, 인스턴스

클래스는 객체를 만들기 위한 설계도 또는 템플릿으로 이해하면 좋다.

```java
class Car {
}
```

객체는 클래스를 바탕으로 만들어진 독립적인 실체이다.

```java
Car c1 = new Car();
```

`new Car()`로 힙 영역에 만들어진 실제 객체를 인스턴스라고도 부른다.

정리:

| 용어               | 의미                      |
| ------------------ | ------------------------- |
| class              | 객체를 만들기 위한 설계도 |
| object             | 클래스를 이용해 만든 객체 |
| instance           | 메모리에 실제 생성된 객체 |
| reference variable | 객체를 참조하는 변수      |

보통 객체와 인스턴스는 비슷한 의미로 사용되지만, 인스턴스는 “특정 클래스로부터 실제 생성된 객체”라는 점을 강조할 때 사용한다.

## 9. 객체지향 프로그래밍의 특징

객체지향 프로그래밍의 대표적인 특징은 캡슐화, 상속, 다형성이다.

## 9-1. 캡슐화

캡슐화는 객체의 내부 구현을 외부에서 직접 접근하지 못하게 숨기는 것이다.

대표적으로 필드를 `private`으로 막고, 필요한 기능만 메서드로 제공한다.

```java
public class Customer {
    private String name;

    public String getName() {
        return name;
    }
}
```

## 9-2. 상속

상속은 자식 클래스가 부모 클래스의 필드와 메서드를 물려받아 사용할 수 있게 하는 것이다.

```java
class Parent {
}

class Child extends Parent {
}
```

상속을 사용하면 기존 코드를 재사용하고 확장할 수 있다.

## 9-3. 다형성

다형성은 같은 사용 방법으로 여러 실행 결과를 낼 수 있는 특징이다.

Java에서는 오버로딩, `인터페이스`, `상속`을 기반으로 하는 `오버라이딩`등의 방법으로 다형성을 구현할 수 있다.

## 10. 클래스 구성 요소

Java 클래스는 다음 요소들로 구성될 수 있다.

| 구성 요소   | 설명                         |
| ----------- | ---------------------------- |
| field       | 데이터 저장 목적의 변수      |
| constructor | 객체 생성 시 호출되는 생성자 |
| method      | 객체 또는 클래스의 기능      |
| block       | `{}`로 묶인 실행 문장        |
| inner class | 클래스 내부에 선언된 클래스  |

예시:

```java
public class Car {
    String model;
    int price;

    Car() {
    }

    Car(String model, int price) {
        this.model = model;
        this.price = price;
    }

    void printInfo() {
        System.out.println(model);
        System.out.println(price);
    }
}
```

## 11. 필드

필드는 클래스 내부에 선언되는 변수이다.

```java
public class Car {
    String model;
    int price;
}
```

필드는 객체의 속성을 저장한다.

```java
Car c1 = new Car();
c1.model = "ABC";
c1.price = 1000;
```

필드는 자동으로 기본값으로 초기화된다.

| 타입      | 기본값     |
| --------- | ---------- |
| 정수 타입 | `0`        |
| 실수 타입 | `0.0`      |
| `boolean` | `false`    |
| `char`    | `'\u0000'` |
| 참조 타입 | `null`     |

반면 메서드 안에 선언한 지역 변수는 자동 초기화되지 않는다.

```java
public void method() {
    int number;

    // System.out.println(number); // 컴파일 오류
}
```

## 12. 생성자

생성자는 메서드처럼 보이지만 반환 타입이 없고, 객체 생성 시 호출된다.

```java
Car c1 = new Car();
```

생성자의 특징:

- 클래스명과 이름이 같다.
- 반환 타입을 쓰지 않는다.
- 객체 생성 시 호출된다.
- 필드 초기화에 자주 사용된다.

```java
public class Car {
    String model;
    int price;

    Car(String model, int price) {  // 생성자 오버로딩
        this.model = model;
        this.price = price;
    }
}
```

## 12-1. 기본 생성자

생성자를 하나도 작성하지 않으면 컴파일러가 기본 생성자를 자동으로 추가한다.

```java
public class Car {
}
```

위 클래스는 다음 생성자가 자동으로 있는 것처럼 동작한다.

```java
public Car() {
}
```

주의할 점:

```java
public class Car {
    Car(String model, int price) {
    }
}
```

생성자를 하나라도 직접 작성하면 컴파일러는 기본 생성자를 자동으로 만들어주지 않는다.
따라서 기본 생성자도 필요하면 직접 작성해야 한다.

```java
public class Car {
    Car() {
    }

    Car(String model, int price) {
    }
}
```

## 13. 생성자 오버로딩과 this

생성자 오버로딩은 같은 클래스 안에서 매개변수가 다른 생성자를 여러 개 정의하는 것이다.

```java
Car() {
}

Car(String model) {
    this.model = model;
}

Car(String model, int price) {
    this.model = model;
    this.price = price;
}
```

매개변수 이름과 필드 이름이 같으면 구분이 필요하다.

```java
this.model = model;
this.price = price;
```

여기서 `this`는 현재 객체를 의미한다.

정리:

| 코드         | 의미                           |
| ------------ | ------------------------------ |
| `model`      | 매개변수 또는 가까운 지역 변수 |
| `this.model` | 현재 객체의 필드               |

## 14. 메서드

메서드는 클래스 내부에 정의하는 기능이다.

```java
void f_info() {
    System.out.println("model = " + this.model);
    System.out.println("price = " + this.price);
}
```

메서드 기본 구조:

```java
[접근제어자] 반환타입 메서드명(매개변수) {
    실행문;
    return 반환값;
}
```

예시:

```java
int add(int a, int b) {
    return a + b;
}
```

반환할 값이 없으면 `void`를 사용한다.

```java
void printInfo() {
    System.out.println("정보 출력");
}
```

## 15. 객체 생성과 사용 흐름

객체 사용 흐름은 보통 다음 순서로 진행된다.

```text
1. 클래스 작성
2. 참조 변수 선언
3. 객체 생성
4. 필드 값 저장
5. 메서드 호출
```

예시:

```java
Car c1;
c1 = new Car();

c1.model = "ABC";
c1.price = 1000;

c1.f_info();
```

또는 선언과 생성을 한 번에 할 수 있다.

```java
Car c2 = new Car("BCD", 30000);
c2.f_info();
```

이 경우 생성자를 오버로딩 하여 매개변수가 있는 생성자를 만들어야 한다.

## 16. CustomerVO 실습

`CustomerVO` 클래스는 고객 정보를 저장하기 위한 객체이다.

```java
public class CustomerVO {
    String customerName;
    String phoneNumber;
    int grade;

    CustomerVO(String customerName, String phoneNumber, int grade) {
        this.customerName = customerName;
        this.phoneNumber = phoneNumber;
        this.grade = grade;
    }

    void infoPrint() {
        System.out.println("이름: " + customerName);
        System.out.println("전화번호: " + phoneNumber);
        System.out.println("등급: " + grade);
    }
}
```

## 17. 다시 볼 부분

- `main(String[] args)`의 값은 Eclipse 설정과 커맨드 창 실행에서 각각 별개로 전달된다는 것을 알았다.
- 기본 생성자는 항상 자동으로 생기는 것이 아니라, 생성자를 하나도 작성하지 않았을 때만 자동으로 추가된다.
- 참조 변수는 스택에 있고, 실제 객체는 힙에 생성된다. 그 후 참조 변수에 실제 객체의 주소 값을 저장한다.
- `object`, `instance`, `reference variable`의 차이를 구분해서 기억해야 한다.
- enum은 단순 문자열 상수보다 타입 안정성이 좋다.
- enum의 `ordinal()`은 순서 기반이므로 분기 로직에 직접 사용하는 것은 조심해야 한다.

## 정리

- `main(String[] args)`는 실행 시 외부에서 전달한 문자열 배열을 받는다.
- Eclipse에서는 Run Configurations의 Program arguments에서 `args` 값을 설정할 수 있다.
- `enum`은 정해진 값의 집합을 타입으로 표현할 수 있다.
- 참조 변수는 스택에 저장되고, `new`로 생성한 객체는 힙에 저장된다.
- 클래스는 객체를 만들기 위한 설계도로 이해하면 좋다.
- 객체와 인스턴스는 비슷하게 사용되지만, 인스턴스는 실제 메모리에 생성된 객체라는 의미가 강하다.
- 객체지향의 주요 특징 3가지는 `캡슐화`, `상속`, `다형성`이다.
- 클래스는 필드, 생성자, 메서드, 블록, 내부 클래스로 구성될 수 있다.
- 생성자를 직접 작성하지 않았을 때는 기본 생성자가 자동으로 추가된다.
- `this`는 현재 객체를 가리킨다.
- 매개변수와 필드 이름이 같을 때는 `this.field`로 구분한다.
- enum 분기는 `ordinal()`보다 enum 값 자체를 사용하는 편이 안전하다.
