## 2. CSS 역할

CSS는 HTML 구조에 스타일을 적용하는 언어다.

```css
selector {
    property: value;
}
```

예시:

```css
h1 {
    color: blue;
    font-size: 24px;
}
```

---

## 3. 선택자

CSS 선택자는 어떤 요소에 스타일을 적용할지 결정한다.

| 선택자 | 예시 | 의미 |
|---|---|---|
| 태그 선택자 | `p` | 모든 p 태그 |
| 클래스 선택자 | `.box` | class가 box인 요소 |
| 아이디 선택자 | `#title` | id가 title인 요소 |
| 그룹 선택자 | `h1, p` | h1과 p 모두 |
| 자식/후손 선택자 | `div p` | div 안의 p |

---

## 4. 우선순위

CSS는 여러 스타일이 동시에 적용될 수 있기 때문에 우선순위가 중요하다.

우선순위는 대략 다음 흐름으로 판단한다.

```text
!important
→ inline style
→ id 선택자
→ class 선택자
→ tag 선택자
→ 작성 순서
```

수업 자료에서도 CSS 적용 우선순위는 중요도, 한정성, 소스 순서 기준으로 정리된다.

## 5. 박스 모델

HTML 요소는 화면에서 박스처럼 계산된다.

```text
content
padding
border
margin
```

`box-sizing: border-box`를 사용하면 width/height 안에 padding과 border까지 포함해서 계산할 수 있다.

```css
* {
    box-sizing: border-box;
}
```

---

## 6. display

`display`는 요소가 화면에서 배치되는 방식을 결정한다.

| 값 | 의미 |
|---|---|
| `block` | 줄 전체를 차지 |
| `inline` | 내용 크기만큼 차지 |
| `inline-block` | inline처럼 흐르지만 크기 지정 가능 |
| `none` | 화면에서 숨김 |
| `flex` | flexbox 레이아웃 |
| `grid` | grid 레이아웃 |

---

## 7. position

`position`은 요소의 위치 계산 방식을 바꾼다.

| 값 | 의미 |
|---|---|
| `static` | 기본 흐름 |
| `relative` | 원래 위치 기준 이동 |
| `absolute` | 가까운 positioned 조상 기준 이동 |
| `fixed` | 브라우저 화면 기준 고정 |
| `sticky` | 스크롤 위치에 따라 고정 |

---

## 8. flexbox와 grid

Flexbox는 한 방향 배치에 적합하고, Grid는 행과 열을 모두 사용하는 2차원 배치에 적합하다.

```css
.container {
    display: flex;
    justify-content: center;
    align-items: center;
}
```

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}
```

---

## 9. transition과 animation

`transition`은 상태 변화가 부드럽게 일어나게 한다.

```css
button {
    transition: background-color 0.3s;
}
```

`animation`은 `@keyframes`를 사용해 여러 단계의 움직임을 정의한다.

```css
@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }
}
```
