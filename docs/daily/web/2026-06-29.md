## 2. DOM 조작

DOM은 HTML 문서를 JavaScript에서 조작할 수 있게 만든 객체 트리다.

```javascript
const title = document.querySelector("#title");
title.textContent = "변경된 제목";
```

DOM 조작은 보통 다음 순서로 진행한다.

```text
요소 선택
→ 값 읽기 또는 수정
→ 스타일 변경
→ 이벤트 연결
```

---

## 3. 이벤트 처리

사용자의 동작에 반응하려면 이벤트를 등록한다.

```javascript
const btn = document.querySelector("#btn");
btn.addEventListener("click", () => {
    console.log("button clicked");
});
```

이벤트는 버튼 클릭, 입력값 변경, 마우스 이동, 키보드 입력 등 다양한 사용자 동작을 처리할 수 있다.

## 4. 배열 메서드

자료에서는 배열 메서드 중 `map`, `filter`, `reduce`를 중요하게 다룬다.

| 메서드 | 역할 |
|---|---|
| `map` | 배열의 각 요소를 변환해 새 배열 생성 |
| `filter` | 조건에 맞는 요소만 골라 새 배열 생성 |
| `reduce` | 배열을 하나의 값으로 누적 |

예시:

```javascript
const prices = [1000, 2000, 3000];
const total = prices.reduce((sum, price) => sum + price, 0);
```

---

## 5. 객체와 구조분해

객체는 key-value 형태로 데이터를 묶는다.

```javascript
const emp = {
    firstName: "Steven",
    salary: 24000
};
```

구조분해를 사용하면 필요한 값을 바로 꺼낼 수 있다.

```javascript
const { firstName, salary } = emp;
```

---

## 6. Spread 문법

Spread 문법은 배열이나 객체를 펼쳐서 새 배열/객체를 만들 때 사용한다.

```javascript
const newEmp = {
    ...emp,
    salary: 25000
};
```

기존 객체를 직접 수정하지 않고 새 객체를 만들 수 있어 상태 관리에 유용하다.
