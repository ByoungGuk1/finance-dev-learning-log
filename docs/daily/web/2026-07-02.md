# 2026-07-02 - jQuery DOM 조작과 Ajax 사원 관리 실습

## 1. 학습 주제

주요 학습 내용

- jQuery DOM 조작
- jQuery Ajax
- Servlet API와 JSON 응답
- 사원 목록 조회/상세/등록/수정/삭제 흐름

---

## 2. Ajax 개요

Ajax는 페이지 전체를 새로고침하지 않고 서버와 데이터를 주고받는 방식이다.

흐름은 다음과 같다.

```text
버튼 클릭
→ JavaScript에서 Ajax 요청
→ Servlet API 실행
→ JSON 응답
→ JavaScript가 화면 일부만 다시 렌더링
```

---

## 3. jQuery Ajax 기본 형태

```javascript
$.ajax({
    url: "/api/emp/list.do",
    type: "get",
    dataType: "json",
    success: (data) => {
        console.log(data);
    }
});
```

`dataType: "json"`은 응답을 JSON으로 해석하겠다는 의미다.

---

## 4. 사원 관리 실습 흐름

사원 관리 실습에서는 다음 기능을 Ajax로 처리했다.

| 기능 | 프론트 함수 | 서버 |
|---|---|---|
| 전체 조회 | `getEmpList()` | `/api/emp/list.do` |
| 상세 조회 | `getEmpDetail()` | `/api/emp/detail.do` |
| 이름 검색 | `getEmpByName()` | `/api/emp/detail.do` |
| 조건 검색 | `findDetailEmpList()` | `/api/emp/find.do` |
| 등록/수정 | `postEmpDetail()` | `/api/emp/insert.do`, `/api/emp/detail.do` |
| 삭제 | `deleteEmp()` | `/api/emp/delete.do` |

---

## 5. 렌더링 흐름

서버에서 받은 사원 목록은 테이블 body에 동적으로 렌더링한다.

```javascript
function renderData(empList) {
    const tbody = $("#empBody");
    tbody.empty();

    $.each(empList, (index, emp) => {
        const empRow = `
            <tr>
                <td>${emp.employeeId}</td>
                <td>${emp.firstName}</td>
                <td>${emp.lastName}</td>
                <td>${emp.email}</td>
                <td>${emp.jobId}</td>
                <td>${emp.departmentId}</td>
                <td>${emp.salary.toLocaleString()}</td>
            </tr>
        `;
        tbody.append(empRow);
    });
}
```

핵심은 서버에서 받은 JSON 배열을 HTML 문자열로 바꿔 테이블에 넣는 것이다.

---

## 6. 이벤트 위임

동적으로 생성된 detail/delete 버튼은 처음 페이지 로드 시 존재하지 않는다.
그래서 부모 요소에 이벤트를 위임한다.

```javascript
$("#empBody").on("click", ".btnEdit", showDetail);
$("#empBody").on("click", ".btnDel", delEmp);
```

이 방식은 나중에 추가된 버튼에도 이벤트가 동작한다.

---

## 7. Servlet API 응답

Servlet API는 JSON 응답을 반환한다.

```java
response.setContentType("application/json");
response.setCharacterEncoding("UTF-8");
response.getWriter().print(new Gson().toJson(result));
```

Java 객체를 JSON 문자열로 바꾸기 위해 Gson을 사용한다.

---

## 8. 다시 볼 부분

- Ajax와 일반 form submit의 차이
- `dataType: "json"`의 의미
- 동적으로 생성된 요소에 이벤트 위임이 필요한 이유
- Servlet에서 JSON 응답을 만들 때 content-type을 지정하는 이유
- 프론트 파라미터 이름과 Servlet `getParameter()` 이름을 맞춰야 하는 이유
