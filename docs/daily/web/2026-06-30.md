## 2. 비동기 처리

JavaScript는 싱글 스레드 기반으로 동작한다.
네트워크 요청처럼 시간이 걸리는 작업을 동기 방식으로 처리하면 화면이 멈출 수 있다.

그래서 비동기 처리를 사용한다.

```text
요청 시작
→ 응답을 기다리는 동안 다른 코드 실행
→ 응답 도착 후 후속 처리
```

---

## 3. Promise

Promise는 비동기 작업의 결과를 표현하는 객체다.

```javascript
fetch(url)
    .then(res => res.json())
    .then(data => console.log(data));
```

---

## 4. async / await

`async / await`는 Promise 기반 코드를 동기 코드처럼 읽기 쉽게 작성하는 문법이다.

```javascript
const getData = async (url) => {
    const res = await fetch(url);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json();
};
```

실습 코드에서도 API 요청 후 `res.ok`를 확인하고 JSON으로 변환하는 흐름을 사용했다.

---

## 5. Fetch API

Fetch API는 브라우저에서 HTTP 요청을 보낼 때 사용한다.

```javascript
const res = await fetch(url);
const data = await res.json();
```

GET 요청은 데이터를 조회할 때 사용하고, POST 요청은 데이터를 생성하거나 전송할 때 사용한다.

```javascript
await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body)
});
```

## 6. localStorage

localStorage는 브라우저에 문자열 데이터를 저장하는 공간이다.
객체나 배열을 저장하려면 JSON 문자열로 변환해야 한다.

```javascript
localStorage.setItem("CART", JSON.stringify(cart));
const cart = JSON.parse(localStorage.getItem("CART") ?? "[]");
```

## 7. 장바구니 실습

장바구니 실습에서는 다음 흐름을 구현했다.

```text
상품 목록 렌더링
→ 담기 버튼 클릭
→ cart 배열에 상품 추가
→ 수량 증가/감소
→ 삭제
→ 총 금액 계산
→ localStorage 저장
```

핵심은 화면 렌더링과 데이터 상태를 함께 관리하는 것이다.

```javascript
const total = cart.reduce((sum, item) => sum + item.price * item.qty, 0);
```

## 8. 메모 기준 추가 확인

메모에는 클로저, `closest`, async-await 오류, axios와 fetch 차이도 다시 볼 내용으로 남아 있다.

- 클로저: 함수가 선언된 외부 스코프의 변수를 기억하는 구조
- closest: 현재 요소에서 가장 가까운 조상 요소를 찾는 DOM 메서드
- fetch: 브라우저 내장 API
- axios: 별도 라이브러리이며 요청/응답 처리 편의 기능이 많음
