## 2. JavaScript 역할

JavaScript는 웹 페이지의 동작을 처리하는 언어다.

HTML이 구조, CSS가 스타일이라면 JavaScript는 사용자 입력과 이벤트에 따라 화면을 바꾸는 역할을 한다.

---

## 3. 변수 선언

JavaScript에서는 `var`, `let`, `const`를 사용할 수 있다.

| 키워드 | 특징 |
|---|---|
| `var` | 함수 스코프. 과거 방식 |
| `let` | 블록 스코프. 값 재할당 가능 |
| `const` | 블록 스코프. 재할당 불가 |

기본적으로 값이 바뀌지 않는 경우 `const`, 바뀌는 경우 `let`을 사용한다.

---

## 4. 자료형

JavaScript는 동적 타입 언어다.

```javascript
let name = "kim";
let age = 20;
let active = true;
let data = null;
let value;
```

| 값 | 의미 |
|---|---|
| `string` | 문자열 |
| `number` | 숫자 |
| `boolean` | true/false |
| `null` | 의도적으로 비어 있음 |
| `undefined` | 값이 할당되지 않음 |
| `object` | 객체 |

---

## 5. 조건문과 반복문

조건문은 특정 조건에 따라 실행 흐름을 나눈다.

```javascript
if (score >= 60) {
    console.log("pass");
} else {
    console.log("fail");
}
```

반복문은 같은 코드를 여러 번 실행할 때 사용한다.

```javascript
for (let i = 0; i < 5; i++) {
    console.log(i);
}
```

---

## 6. 함수

함수는 반복되는 로직을 묶는 단위다.

```javascript
function add(a, b) {
    return a + b;
}
```

화살표 함수도 사용할 수 있다.

```javascript
const add = (a, b) => a + b;
```

---

## 7. DOM과 window.onload

DOM은 HTML 문서를 JavaScript가 조작할 수 있도록 객체 구조로 표현한 것이다.

메모에서는 다음 내용을 정리했다.

```javascript
window.onload = () => {}
```

이는 body가 로드된 후 JavaScript 코드가 동작하도록 하기 위한 방식이다.
HTML 요소가 아직 만들어지기 전에 JS가 실행되면 요소를 찾지 못할 수 있다.

---

## 8. DOM 선택 예시

```javascript
const title = document.querySelector("#title");
title.textContent = "변경된 제목";
```

버튼 이벤트는 다음처럼 연결할 수 있다.

```javascript
const btn = document.querySelector("#btn");
btn.addEventListener("click", () => {
    console.log("click");
});
```
