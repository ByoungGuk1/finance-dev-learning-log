## 2. jQuery 개요

jQuery는 JavaScript DOM 조작을 간결하게 작성하기 위한 라이브러리다.

기본 형태는 다음과 같다.

```javascript
$(selector).method();
```

예시:

```javascript
$("#btn").on("click", function () {
    console.log("click");
});
```

---

## 3. 문서 준비 이벤트

jQuery에서는 DOM이 준비된 후 코드를 실행하기 위해 다음 형태를 자주 사용한다.

```javascript
$(() => {
    // DOM 준비 후 실행
});
```

이는 순수 JavaScript의 `window.onload` 또는 `DOMContentLoaded`와 비슷한 목적이다.

---

## 4. 선택자

jQuery 선택자는 CSS 선택자와 유사하게 사용할 수 있다.

```javascript
$("p")
$(".item")
$("#title")
$("div p")
```

선택한 요소에 대해 텍스트, 속성, 스타일을 변경할 수 있다.

```javascript
$("#title").text("변경된 제목");
$("#box").css("background", "yellow");
```

---

## 5. 이벤트 처리

이벤트는 `.on()`을 사용해 연결한다.

```javascript
$("#btn").on("click", function () {
    alert("clicked");
});
```

동적으로 생성되는 요소에는 이벤트 위임을 사용할 수 있다.

```javascript
$("#list").on("click", ".item", function () {
    console.log($(this).text());
});
```

이 방식은 나중에 추가된 요소에도 이벤트가 적용된다는 장점이 있다.

---

## 6. 체이닝

jQuery는 메서드 호출 결과로 다시 jQuery 객체를 반환하는 경우가 많아 체이닝이 가능하다.

```javascript
$("#box")
    .text("hello")
    .css("color", "red")
    .show();
```

---

## 7. DOM 탐색

DOM 탐색은 선택한 요소 주변의 부모, 자식, 형제 요소를 찾는 기능이다.

```javascript
$(this).parent();
$(this).children();
$(this).closest("tr");
$(this).find("input");
```

특히 `closest()`는 현재 요소에서 가장 가까운 조상 요소를 찾을 때 사용한다.
