---

## 2. HTML 구조 태그

HTML은 웹 페이지의 구조를 작성하는 언어다.

대표적인 구조 태그는 다음과 같다.

| 태그 | 역할 |
|---|---|
| `h1` ~ `h6` | 제목 |
| `p` | 문단 |
| `ul`, `ol`, `li` | 목록 |
| `table`, `tr`, `th`, `td` | 표 |
| `img` | 이미지 |
| `a` | 하이퍼링크 |
| `form` | 사용자 입력 양식 |

시맨틱 태그를 사용하면 문서 구조를 더 명확하게 표현할 수 있다.

```html
<header></header>
<nav></nav>
<main></main>
<section></section>
<footer></footer>
```

---

## 3. 입력 양식

입력 양식은 사용자가 데이터를 입력하고 서버로 전송하기 위한 구조다.

```html
<form action="/save" method="post">
    <label for="userId">아이디</label>
    <input type="text" id="userId" name="userId">
    <button type="submit">전송</button>
</form>
```

`form`에서 중요한 속성은 다음과 같다.

| 속성 | 의미 |
|---|---|
| `action` | 요청을 보낼 서버 주소 |
| `method` | 요청 방식. GET 또는 POST |
| `name` | 서버로 전달되는 파라미터 이름 |
| `value` | 서버로 전달되는 값 |

---

## 4. input type

입력 타입에 따라 브라우저의 입력 UI가 달라진다.

```html
<input type="text">
<input type="password">
<input type="number">
<input type="date">
<input type="radio">
<input type="checkbox">
<input type="file">
```

서버로 값을 넘기려면 `name` 속성이 필요하다.

---

## 5. select / textarea

`select`는 여러 선택지 중 하나를 고르게 할 때 사용한다.

```html
<select name="jobId">
    <option value="IT_PROG">프로그래머</option>
    <option value="SA_REP">영업</option>
</select>
```

`textarea`는 여러 줄 입력이 필요할 때 사용한다.

```html
<textarea name="content"></textarea>
```

---

## 6. 접근성 관점

입력 필드는 가능하면 `label`과 함께 사용한다.

```html
<label for="email">이메일</label>
<input type="email" id="email" name="email">
```

`label`의 `for`와 `input`의 `id`가 연결되면 화면 낭독기나 클릭 동작에서 더 명확하게 동작한다.

---

## 7. 다시 볼 부분

- `id`와 `name`의 차이
- GET과 POST의 차이
- `label for`와 `input id` 연결 방식
- `select option`에서 서버로 넘어가는 값은 화면 텍스트가 아니라 `value`라는 점
