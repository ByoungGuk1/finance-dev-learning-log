## 2. 예외 처리 복습

예외 처리는 프로그램 실행 중 발생할 수 있는 문제를 처리해서 프로그램 흐름을 이어가기 위한 방법이다.

```java
try {
    int result = 10 / 0;
    System.out.println(result);
} catch (ArithmeticException e) {
    System.err.println(e.getMessage());
} finally {
    System.out.println("finally 수행");
}
```

`finally`는 예외 발생 여부와 관계없이 실행된다.

`catch` 문에서 `return`을 하더라도 `finally`가 실행되는 것을 확인할 수 있다.

```java
catch (ArithmeticException e) {
    System.err.println(e.getMessage());
    return;
} finally {
    System.out.println("finally 수행");
}
```

정리:

- `try`에는 예외가 발생할 수 있는 코드를 작성한다.
- `catch`에는 예외 발생 시 처리할 코드를 작성한다.
- `finally`는 예외 발생 여부와 관계없이 실행된다.
- `catch`에서 `return`을 하더라도 `finally`는 실행된다.
- 예외 처리 코드는 비즈니스 로직과 분리해서 보는 것이 좋다.

## 3. try-with-resources

try-with-resources는 사용한 자원을 자동으로 닫아주는 문법이다.

파일, 입력 스트림, `Scanner`처럼 사용 후 닫아야 하는 자원을 처리할 때 사용할 수 있다.

```java
try (FileReader fr = new FileReader("src/com/shinhan/day11/resourceTest.txt")) {
    int data;

    while ((data = fr.read()) != -1) {
        System.out.print((char) data);
    }
} catch (IOException e) {
    System.err.println(e.getMessage());
}
```

기존 방식에서는 `finally`에서 직접 `close()`를 호출해야 했다.

```java
FileReader fr = null;

try {
    fr = new FileReader("src/com/shinhan/day11/resourceTest.txt");
} catch (IOException e) {
    System.err.println(e.getMessage());
} finally {
    if (fr != null) {
        try {
            fr.close();
        } catch (IOException e) {
            System.err.println(e.getMessage());
        }
    }
}
```

try-with-resources에 들어가는 객체는 `AutoCloseable`을 구현하고 있어야 한다.

```java
class CustomFileWriter implements AutoCloseable {
    @Override
    public void close() throws IOException {
        System.out.println("파일 닫기");
    }
}
```

정리:

- try-with-resources는 자원을 자동으로 닫아준다.
- `finally`에서 직접 `close()`를 호출하는 코드를 줄일 수 있다.
- try-with-resources에 들어가는 객체는 `AutoCloseable`을 구현해야 한다.
- 파일, 스트림, `Scanner`처럼 닫아야 하는 자원에서 자주 사용된다.

## 4. `Object` 클래스

`Object`는 Java의 최상위 클래스이다.

모든 클래스는 직접 또는 간접적으로 `Object`를 상속받는다.

대표적인 메서드는 다음과 같다.

| 메서드       | 역할                  |
| ------------ | --------------------- |
| `toString()` | 객체를 문자열로 표현  |
| `hashCode()` | 객체의 해시 코드 반환 |
| `equals()`   | 객체의 동등성 비교    |

기본 `toString()`은 클래스명과 해시 코드 기반 문자열을 출력한다.

```java
Object obj = new Object();

System.out.println(obj);
System.out.println(obj.toString());
System.out.println(obj.hashCode());
```

정리:

- 모든 클래스는 `Object`를 상속받는다.
- `toString()`은 객체의 문자열 표현을 반환한다.
- `hashCode()`는 해시 기반 자료구조에서 사용된다.
- `equals()`는 객체의 동등성 비교에 사용된다.

## 5. `equals()`와 `hashCode()`

기본 `equals()`는 객체의 참조값을 비교한다.

```java
Object obj1 = new Object();
Object obj2 = new Object();

System.out.println(obj1.equals(obj2));
```

하지만 `String`은 `equals()`가 재정의되어 있어서 문자열 내용을 비교한다.

```java
String s1 = new String("abc");
String s2 = new String("abc");

System.out.println(s1.equals(s2)); // true
```

직접 만든 클래스에서 값 기준 비교를 하려면 `equals()`를 재정의해야 한다.

```java
@Override
public boolean equals(Object obj) {
    if (!(obj instanceof Money money)) {
        return false;
    }

    return this.amount == money.amount;
}
```

`equals()`를 재정의할 때는 보통 `hashCode()`도 함께 재정의해야 한다.  
특히 `HashSet`, `HashMap`처럼 해시 기반 컬렉션을 사용할 때 중요하다.

```java
@Override
public int hashCode() {
    return Integer.hashCode(amount);
}
```

정리:

- 기본 `equals()`는 참조값을 비교한다.
- 값 기준 비교가 필요하면 `equals()`를 재정의해야 한다.
- `equals()`를 재정의하면 `hashCode()`도 같이 재정의하는 것이 좋다.
- `HashSet`은 중복 여부를 확인할 때 `hashCode()`와 `equals()`를 사용한다.

## 6. `record`

`record`는 값을 담는 객체를 간단히 만들기 위한 문법이다.

```java
public record Person(String name, int age) {
}
```

위 코드만으로 생성자, 접근자, `toString()`, `equals()`, `hashCode()`가 자동으로 만들어진다.

사용할 때는 필드명과 같은 이름의 메서드를 호출한다.

```java
Person p1 = new Person("김길동", 20);

System.out.println(p1.name());
System.out.println(p1.age());
System.out.println(p1);
```

정리:

- `record`는 데이터 전달 목적의 클래스를 간단히 만들 때 사용할 수 있다.
- 생성자, 접근자, `toString()`, `equals()`, `hashCode()`가 자동 생성된다.
- getter 이름은 `getName()`이 아니라 `name()` 형태이다.
- 값을 담는 객체를 간결하게 작성할 수 있다.

## 7. Lombok

Lombok은 반복적으로 작성하는 코드를 어노테이션으로 줄여주는 라이브러리이다.

```java
@RequiredArgsConstructor
@AllArgsConstructor
@Data
public class Member {
    private final String id;

    @NonNull
    private String name;

    private int age;
}
```

주요 어노테이션 역할:

| 어노테이션                 | 역할                                                        |
| -------------------------- | ----------------------------------------------------------- |
| `@Data`                    | getter, setter, `toString()`, `equals()`, `hashCode()` 생성 |
| `@RequiredArgsConstructor` | `final` 필드와 `@NonNull` 필드를 받는 생성자 생성           |
| `@AllArgsConstructor`      | 모든 필드를 받는 생성자 생성                                |
| `@NoArgsConstructor`       | 기본 생성자 생성                                            |
| `@EqualsAndHashCode`       | `equals()`와 `hashCode()` 생성                              |
| `@ToString`                | `toString()` 생성                                           |

정리:

- Lombok은 반복 코드를 줄여준다.
- IDE와 Build Path에 Lombok 설정이 필요하다.
- `@RequiredArgsConstructor`는 `final` 필드와 `@NonNull` 필드를 대상으로 생성자를 만든다.

## 8. 문자열 인코딩

문자열을 바이트 배열로 변환하면 인코딩 방식에 따라 바이트 수가 달라진다.

```text
UTF-8  : 한글 1자 3바이트
EUC-KR : 한글 1자 2바이트
```

```java
String text = "이것이 자바다";

byte[] byteArr = text.getBytes();
char[] charArr = text.toCharArray();

System.out.println(byteArr.length);
System.out.println(charArr.length);
```

`getBytes()`는 문자열을 바이트 배열로 바꾸고, `toCharArray()`는 문자 배열로 바꾼다.

정리:

- 문자열은 인코딩 방식에 따라 바이트 수가 달라질 수 있다.
- Eclipse에서 UTF-8을 사용하면 한글 1자는 보통 3바이트로 인코딩된다.
- `getBytes()`는 바이트 배열을 만든다.
- `toCharArray()`는 문자 배열을 만든다.
- 문자열 깨짐은 인코딩 방식이 맞지 않을 때 발생할 수 있다.

## 9. `StringBuilder`

`String`은 불변 객체이기 때문에 문자열을 반복해서 수정하면 새로운 문자열 객체가 계속 만들어질 수 있다.  
문자열을 자주 변경해야 한다면 `StringBuilder`를 사용하는 것이 좋다.

```java
StringBuilder sb = new StringBuilder("자바");

sb.append("프로그램");
sb.insert(sb.length(), "!");
System.out.println(sb);
```

자주 사용하는 메서드:

| 메서드       | 역할             |
| ------------ | ---------------- |
| `append()`   | 문자열 뒤에 추가 |
| `insert()`   | 지정 위치에 삽입 |
| `delete()`   | 지정 범위 삭제   |
| `replace()`  | 지정 범위 치환   |
| `toString()` | 최종 문자열 반환 |

정리:

- 문자열을 반복해서 수정할 때는 `StringBuilder`를 사용할 수 있다.
- `append`, `insert`, `delete`, `replace`, `toString`을 사용한다.

## 10. `StringTokenizer`와 `split()`

문자열을 기준 문자로 나눌 때 `StringTokenizer`와 `split()`을 사용할 수 있다.

```java
String datas = "이름1:1/이름2:2/이름3:3,이름4 4";

String[] arr = datas.split(":|/|,| ");
System.out.println(Arrays.toString(arr));
```

`split()`은 정규 표현식을 기준으로 문자열을 나눈다.

```java
StringTokenizer st = new StringTokenizer(datas, ":|/|,| ");

while (st.hasMoreTokens()) {
    System.out.println(st.nextToken());
}
```

`StringTokenizer`는 전달한 문자들을 각각 구분자로 사용한다.  
정규 표현식이 아니라 구분 문자 목록으로 동작한다.

정리:

- `split()`은 정규 표현식을 기준으로 문자열을 나눈다.
- `StringTokenizer`는 지정한 구분 문자 기준으로 토큰을 나눈다.
- 간단한 구분자 처리는 `StringTokenizer`로도 가능하다.
- 정규 표현식 기반 분리가 필요하면 `split()`이 더 적합하다.

## 11. 날짜 표현 타입

Java에서는 날짜와 시간을 여러 타입으로 다룰 수 있다.

### `java.util.Date`

레거시 코드에서 자주 볼 수 있는 날짜 타입이다.

```java
Date date = new Date();
System.out.println(date);
```

### `java.sql.Date`

DB의 `DATE` 타입과 연동할 때 사용할 수 있다.

```java
java.sql.Date day = new java.sql.Date(new Date().getTime());
System.out.println(day);
```

### `Calendar`

날짜의 연, 월, 일을 개별적으로 가져올 수 있다.

```java
Calendar cal = Calendar.getInstance();

System.out.println(cal.get(Calendar.YEAR));
System.out.println(cal.get(Calendar.MONTH) + 1);
System.out.println(cal.get(Calendar.DATE));
```

`Calendar.MONTH`는 0부터 시작하므로 실제 월을 출력하려면 `+ 1`이 필요하다.

### `LocalDate`, `LocalDateTime`

현재 Java에서 자주 사용하는 날짜/시간 API이다.

```java
LocalDate ld = LocalDate.now();
LocalDate birth = LocalDate.of(1999, 3, 23);

LocalDateTime ldt = LocalDateTime.now();
```

### `Timestamp`

날짜와 시간을 DB와 연동할 때 사용할 수 있다.

```java
Timestamp timestamp = Timestamp.valueOf(ldt);
Timestamp fixed = Timestamp.valueOf("2026-12-25 12:00:00");
```

정리:

- `java.util.Date`, `Calendar`는 레거시 코드에서 자주 볼 수 있다.
- `java.sql.Date`는 DB의 날짜 타입과 연동할 때 사용한다.
- `LocalDate`, `LocalDateTime`은 현재 Java에서 날짜와 시간을 다룰 때 많이 사용한다.
- `Timestamp`는 날짜와 시간 정보를 DB와 연결할 때 사용할 수 있다.

## 12. `DecimalFormat`

`DecimalFormat`은 숫자를 원하는 형식의 문자열로 바꿀 때 사용한다.

```java
double money = 1234567.816;

DecimalFormat df = new DecimalFormat("#,###.##");
System.out.println(df.format(money));
```

자주 사용하는 패턴:

| 패턴        | 의미                    |
| ----------- | ----------------------- |
| `0`         | 정수 표시               |
| `0.0`       | 소수 1자리 강제         |
| `#.#`       | 소수 1자리, 없으면 생략 |
| `0000.0000` | 자릿수 0으로 채움       |
| `#,###`     | 천 단위 구분            |
| `#,###.##`  | 천 단위와 소수 표시     |
| `₩#,###`    | 원화 기호               |
| `#.##E0`    | 지수 표현               |
| `0.00%`     | 퍼센트 표현             |

정리:

- `DecimalFormat`은 숫자 출력 형식을 지정할 때 사용한다.
- `0`은 자릿수를 강제로 채우고, `#`은 값이 없으면 생략한다.
- 금액, 퍼센트, 지수 표현 등에 사용할 수 있다.

## 13. `SimpleDateFormat`

`SimpleDateFormat`은 날짜를 원하는 문자열 형식으로 바꿀 때 사용한다.

```java
Date date = new Date();

SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");
System.out.println(sdf.format(date));
```

사용 패턴 예시:

| 패턴                      | 예시             |
| ------------------------- | ---------------- |
| `yyyy-MM-dd`              | 2026-05-29       |
| `yyyy/MM/dd`              | 2026/05/29       |
| `yyyy년 MM월 dd일`        | 2026년 05월 29일 |
| `HH:mm:ss`                | 14:30:10         |
| `hh:mm:ss a`              | 02:30:10 오후    |
| `yyyy-MM-dd HH:mm:ss.SSS` | 밀리초 포함      |
| `yyyy-MM-dd'T'HH:mm:ss`   | ISO 8601 형태    |

주의할 점:

```java
new SimpleDateFormat("yyyy-MM-dd hh-mm-ss");
```

`hh`는 12시간 기준이고, `HH`는 24시간 기준이다.

정리:

- `SimpleDateFormat`은 날짜를 문자열로 포맷할 때 사용한다.
- `yyyy`, `MM`, `dd`, `HH`, `mm`, `ss` 같은 패턴을 사용한다.
- 24시간 기준 시간은 `HH`를 사용한다.
- `MM`은 월, `mm`은 분을 의미한다.

## 14. 정규 표현식

정규 표현식은 문자열이 특정 패턴을 만족하는지 확인하거나, 특정 패턴을 찾아낼 때 사용한다.

전화번호 형식 확인:

```java
String phoneNumber = "010-1234-5678";
String regExp = "[01]{3}-\\d{3,4}-[0-9]{4}";

boolean result = Pattern.matches(regExp, phoneNumber);
```

문자열에서 전화번호 찾기:

```java
String text = "고객센터010-1234-1234 또는 02-5678-5678 팩스는 031-9000-9111";
String regExp = "(\\d{2,3})-(\\d{3,4})-(\\d{4})";

Pattern pattern = Pattern.compile(regExp);
Matcher matcher = pattern.matcher(text);

while (matcher.find()) {
    System.out.println(matcher.group());
    System.out.println(matcher.group(1));
    System.out.println(matcher.group(2));
    System.out.println(matcher.group(3));
}
```

괄호 `()`를 사용하면 캡처 그룹을 만들 수 있다.  
`group(1)`, `group(2)`처럼 각 그룹을 따로 꺼낼 수 있다.

이메일 예시는 더미 값을 사용했다.

```java
String text = "고객센터 user01@example.com 또는 user02@test.com";
String regExp = "\\b([A-Za-z][A-Za-z0-9._%+-]*)@([A-Za-z0-9.-]+\\.[A-Za-z]{2,})\\b";
```

정리:

- `Pattern.matches()`는 전체 문자열이 패턴과 일치하는지 확인한다.
- `Pattern.compile()`과 `Matcher`를 사용하면 문자열 안에서 패턴을 찾을 수 있다.
- `matcher.find()`는 다음 매칭 결과를 찾는다.
- `group()`은 전체 매칭 결과를 반환한다.
- `group(1)`, `group(2)`는 캡처 그룹을 반환한다.

## 15. 리플렉션

리플렉션은 클래스의 메타 정보를 프로그램에서 확인하는 기능이다.

```java
Class<?> cls = Account.class;
System.out.println(cls.getSimpleName());
```

클래스 이름으로 클래스 정보를 가져올 수 있다.

```java
Class<?> cls = Class.forName("com.shinhan.day07.Account");
```

클래스 경로를 사용하여 클래스 정보를 가져올 수도 있다.

필드 정보를 조회할 수도 있다.

```java
Field[] fields = cls.getDeclaredFields();

for (Field field : fields) {
    System.out.println(field.getName());
    System.out.println(Modifier.toString(field.getModifiers()));
    System.out.println(field.getType().getSimpleName());
}
```

정리:

- 리플렉션은 클래스의 메타 정보를 확인하는 기능이다.
- `Class<?>` 타입을 사용해 클래스 정보를 다룬다.
- `Class.forName()`으로 문자열 기반 클래스 로딩을 할 수 있다.
- `getFields()`는 public 필드 중심으로 조회한다.
- `getDeclaredFields()`는 선언된 필드를 접근 제한자와 관계없이 조회한다.
- `Modifier.toString()`으로 접근 제한자 정보를 문자열로 확인할 수 있다.

## 16. 리소스 파일 읽기

클래스 기준으로 같은 패키지에 있는 리소스 파일을 읽을 수 있다.

```java
Class<?> cls = DateExample.class;

InputStream is = cls.getResourceAsStream("resourceTest.txt");
InputStreamReader isr = new InputStreamReader(is);
```

이 방식은 `resourceTest.txt`가 `DateExample.class`와 같은 클래스패스 위치에 있을 때 사용할 수 있다.

정리:

- `getResource()`는 리소스의 경로 정보를 가져온다.
- `getResourceAsStream()`은 리소스를 입력 스트림으로 가져온다.
- 리소스 파일 위치가 맞지 않으면 `null`이 될 수 있다.

## 17. 어노테이션

어노테이션은 코드에 붙이는 설정 정보이다.  
클래스, 메서드, 필드 등을 컴파일하거나 실행할 때 어떻게 처리할지 알려줄 수 있다.

어노테이션은 다음 목적으로 사용할 수 있다.

```text
1. 컴파일 시 사용하는 정보 전달
2. 빌드 툴이 코드를 자동 생성할 때 사용하는 정보 전달
3. 실행 시 특정 기능을 처리할 때 사용하는 정보 전달
```

어노테이션 선언:

```java
@Target({ ElementType.METHOD })
@Retention(RetentionPolicy.RUNTIME)
public @interface PrintAnnotation {
    String value() default "-";
    int number() default 7;
}
```

사용:

```java
public class PrintService {
    @PrintAnnotation("*")
    public void method1() {
        System.out.println("method1() 실행");
    }

    @PrintAnnotation(value = "#", number = 20)
    public void method2() {
        System.out.println("method2() 실행");
    }
}
```

리플렉션으로 메서드에 붙은 어노테이션을 읽을 수 있다.

```java
Method[] declaredMethods = PrintService.class.getDeclaredMethods();

for (Method method : declaredMethods) {
    PrintAnnotation printAnnotation = method.getAnnotation(PrintAnnotation.class);

    printLine(printAnnotation);
    method.invoke(new PrintService());
    printLine(printAnnotation);
}
```

정리:

- 어노테이션은 `@`로 작성하는 설정 정보이다.
- `@Target`은 어노테이션을 붙일 수 있는 위치를 지정한다.
- `@Retention`은 어노테이션 정보가 유지되는 범위를 지정한다.
- `RetentionPolicy.RUNTIME`이면 실행 중 리플렉션으로 읽을 수 있다.
- `method.invoke()`를 사용하면 리플렉션으로 메서드를 실행할 수 있다.

## 18. 다시 볼 부분

- `catch`에서 `return`을 하더라도 `finally`는 실행된다.
- try-with-resources는 자원을 자동으로 닫아준다.
- `equals()`를 재정의하면 `hashCode()`도 같이 고려해야 한다.
- `HashSet`은 중복 판단에 `hashCode()`와 `equals()`를 사용한다.
- `record`는 생성자, 접근자, `toString()`, `equals()`, `hashCode()`를 자동 생성한다.
- Lombok의 `@RequiredArgsConstructor`는 `final` 필드와 `@NonNull` 필드를 대상으로 생성자를 만든다.
- 문자열 수정이 많으면 `StringBuilder`를 사용할 수 있다.
- `split()`은 정규 표현식 기준으로 문자열을 나눈다.
- `StringTokenizer`는 지정한 구분 문자 기준으로 토큰을 나눈다.
- `Calendar.MONTH`는 0부터 시작한다.
- `DecimalFormat`에서 `0`은 자릿수를 채우고, `#`은 값이 없으면 생략한다.
- 정규 표현식의 괄호 `()`는 캡처 그룹을 만든다.
- `getFields()`와 `getDeclaredFields()`의 차이를 구분해야 한다.
- `getResourceAsStream()`은 리소스를 스트림으로 읽는다.
- `@Retention(RetentionPolicy.RUNTIME)`인 경우, 실행 중 어노테이션 정보를 읽을 수 있다.
- `method.invoke()`로 리플렉션 기반 메서드 호출이 가능하다.

---

## 정리

- 예외 처리에서 `finally`는 예외 발생 여부와 관계없이 실행된다.
- try-with-resources는 `AutoCloseable` 자원을 자동으로 닫아준다.
- `Object` 클래스는 모든 클래스의 최상위 클래스이다.
- `toString()`, `hashCode()`, `equals()`는 객체 비교와 출력에서 자주 사용된다.
- `equals()`를 재정의하면 `hashCode()`도 함께 고려해야 한다.
- `record`는 데이터를 담는 클래스를 간단히 만들 수 있는 문법이다.
- Lombok은 반복 코드를 어노테이션으로 줄여준다.
- 문자열은 인코딩 방식에 따라 바이트 수가 달라진다.
- `StringBuilder`는 문자열을 자주 수정할 때 사용할 수 있다.
- 날짜와 시간은 `Date`, `Calendar`, `LocalDate`, `LocalDateTime`, `Timestamp` 등으로 다룰 수 있다.
- `DecimalFormat`은 숫자 출력 형식을 지정한다.
- `SimpleDateFormat`은 날짜 출력 형식을 지정한다.
- 정규 표현식은 문자열 패턴 검사와 추출에 사용된다.
- 리플렉션은 클래스의 메타 정보를 프로그램에서 확인하는 기능이다.
- 어노테이션은 코드에 붙이는 설정 정보이다.
- `@Retention(RetentionPolicy.RUNTIME)`을 사용하면 실행 중 어노테이션 정보를 읽을 수 있다.
