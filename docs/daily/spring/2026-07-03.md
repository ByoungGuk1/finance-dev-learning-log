## 2. Spring Boot 개요

Spring Boot는 Spring Framework를 더 쉽게 사용하기 위한 도구다.

자료 기준으로 Spring Boot는 다음처럼 정리할 수 있다.

```text
Spring Boot = Spring Framework + 자동 설정 + 내장 Tomcat
```

기존 Servlet/JSP 프로젝트에서는 Tomcat과 설정을 직접 신경 써야 했지만, Spring Boot는 내장 Tomcat을 포함하고 있어서 애플리케이션을 바로 실행할 수 있다.

---

## 3. 프로젝트 생성 흐름

Spring Boot 프로젝트는 Spring Initializr를 사용해 생성한다.

기본 선택 흐름은 다음과 같다.

```text
Project: Gradle
Language: Java
Spring Boot Version 선택
Dependencies: Spring Web, Lombok, DevTools 등
```

실습 코드에서는 `bananaapp` 프로젝트를 기준으로 Spring Boot 애플리케이션을 실행한다.

```java
@SpringBootApplication
public class BananaappApplication {
    public static void main(String[] args) {
        SpringApplication.run(BananaappApplication.class, args);
    }
}
```

## 4. Controller

Spring Boot에서는 `@RestController`를 사용해 HTTP 요청에 응답하는 클래스를 만들 수 있다.

```java
@RestController
public class SampleController {
    @GetMapping("/hello")
    public String f1() {
        return "Hello";
    }
}
```

`@RestController`는 `@Controller`와 `@ResponseBody`가 합쳐진 형태로 볼 수 있다.
문자열이나 객체를 반환하면 HTTP 응답 body로 전달된다.

## 5. DTO와 Lombok

실습에서는 `CarDTO`, `AccountDTO` 같은 DTO를 만들고 Lombok을 적용했다.

```java
@Getter
@Setter
@Builder
@NoArgsConstructor
@AllArgsConstructor
@ToString
public class CarDTO {
    private String model;
    private int price;
}
```

Lombok을 사용하면 getter/setter, 생성자, builder 등의 반복 코드를 줄일 수 있다.

## 6. IoC

IoC는 제어의 역전이다.

기존 방식은 개발자가 직접 객체를 생성한다.

```java
TV tv = new SamsungTV();
```

Spring에서는 객체 생성과 의존성 연결을 컨테이너가 담당한다.

```text
개발자가 직접 new
→ Spring Container가 Bean 생성 및 주입
```

---

## 7. DI

DI는 Dependency Injection, 즉 의존성 주입이다.

객체가 필요한 의존 객체를 직접 생성하지 않고 외부에서 주입받는다.

자료와 메모 기준으로 DI는 다음 방식으로 정리된다.

- Field Injection: `@Autowired`
- Constructor Injection: 생성자 주입
- Lombok 사용 시 `@RequiredArgsConstructor` + `final` 필드 방식

Spring에서는 생성자 주입을 권장한다.

---

## 8. Bean과 Component

Spring 컨테이너가 관리하는 객체를 Bean이라고 한다.

Bean 등록 방식은 다음과 같다.

```java
@Component
@Service
@Repository
@Controller
```

또는 설정 클래스에서 `@Bean` 메서드로 등록할 수도 있다.

```java
@Configuration
public class AppConfig {
    @Bean
    public MyService myService() {
        return new MyService();
    }
}
```

---

## 9. AOP

AOP는 Aspect Oriented Programming, 관점 지향 프로그래밍이다.

핵심 로직과 공통 관심사를 분리하기 위해 사용한다.

예시:

```text
핵심 로직: 계좌 조회, 입금, 출금
공통 관심사: 로그, 실행 시간 측정, 트랜잭션, 보안
```

수업 자료에서는 `PerformanceAspect`를 통해 메서드 실행 시간을 로깅하는 흐름을 다뤘다.
