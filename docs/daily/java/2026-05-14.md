# 2026-05-14 - Java 기본 문법

## 1. Java 파일과 클래스 특징

- 하나의 `.java` 파일 안에 여러 개의 클래스를 정의할 수 있다.
- 단, `public` 클래스는 하나만 선언할 수 있다.
- `public` 클래스가 있는 경우 파일명은 `public` 클래스명과 같아야 한다.

예시:

```java
public class Main {
}

class SubClass {
}
```

이 경우 파일명은 `Main.java`가 되어야 한다.

## 2. Java 클래스 구성 요소

Java 클래스는 다음 요소들로 구성될 수 있다.

1. 필드 field
2. 생성자 constructor
3. 메서드 method
4. 초기화 블록 instance block, static block
5. 내부 클래스 inner class

```java
public class Person {
    // field
    String name;

    // constructor
    public Person(String name) {
        this.name = name;
    }

    // method
    public void printName() {
        System.out.println(name);
    }

    // instance block
    {
        System.out.println("instance block");
    }

    // static block
    static {
        System.out.println("static block");
    }

    // inner class
    class Address {
    }
}
```

## 3. Java 변수 타입

Java의 변수 타입은 크게 기본 타입과 참조 타입으로 나눌 수 있다.

## 3-1. 기본 타입 primitive type

기본 타입은 값을 직접 저장하며, 연산과 값 비교에 사용된다.

### 정수 타입

| 타입    |   크기 | 범위 또는 특징        |
| ------- | -----: | --------------------- |
| `byte`  | 1 byte | -128 ~ 127            |
| `short` | 2 byte | -32,768 ~ 32,767      |
| `char`  | 2 byte | 0 ~ 65,535, 문자 저장 |
| `int`   | 4 byte | 약 -21억 ~ 21억       |
| `long`  | 8 byte | 큰 정수 저장          |

정수 리터럴의 기본 타입은 `int`이다.

```java
byte v1 = Byte.MAX_VALUE;       // 127
byte mv1 = Byte.MIN_VALUE;      // -128

short v2 = Short.MAX_VALUE;     // 32767
short mv2 = Short.MIN_VALUE;    // -32768

char v3 = 'a';                  // 문자 저장
int v4 = Integer.MAX_VALUE;     // 2147483647
int mv4 = Integer.MIN_VALUE;    // -2147483648

long v5 = Long.MAX_VALUE;
```

`long` 타입에 큰 정수 리터럴을 저장할 때는 `L`을 붙인다.

```java
long number = 10000000000L;
```

---

### 실수 타입

| 타입     |   크기 | 특징          |
| -------- | -----: | ------------- |
| `float`  | 4 byte | 단정밀도 실수 |
| `double` | 8 byte | 배정밀도 실수 |

실수 리터럴의 기본 타입은 `double`이다.

```java
float v1 = 3.14f;
double v2 = 3.14;
```

---

### 논리 타입

논리 타입은 `boolean`이며, 값은 `true` 또는 `false`만 가질 수 있다.

```java
boolean isActive = true;
boolean isDeleted = false;
```

## 3-2. 문자열 타입 String

`String`은 Java의 기본 타입은 아니고, 문자열을 다루기 위한 클래스 타입이다.

- 위치: `java.lang.String`
- 기본 타입은 아니지만 자주 사용되기 때문에 기본 타입처럼 사용된다.
- 문자열 리터럴은 문자열 상수 풀 String Constant Pool에 저장된다.

```java
String name = "Java";
```

## 4. String 값 비교

기본 타입은 `==`으로 값을 비교할 수 있다.

```java
int a = 100;
int b = 100;

System.out.println(a == b); // true
```

하지만 `String`은 참조 타입이므로 `==`은 주소값을 비교한다.  
문자열의 실제 내용을 비교할 때는 `equals()`를 사용해야 한다.

```java
String s1 = "자바";
String s2 = "자바";
String s3 = new String("자바");
String s4 = new String("자바");

System.out.println(s1 == s2);      // true
System.out.println(s3 == s4);      // false

System.out.println(s1.equals(s4)); // true
System.out.println(s3.equals(s4)); // true
```

객체의 식별 해시값을 확인할 수도 있다.

```java
System.out.println(System.identityHashCode(s1));
System.out.println(System.identityHashCode(s2));
System.out.println(System.identityHashCode(s3));
System.out.println(System.identityHashCode(s4));
```

정리하면 다음과 같다.

| 비교 방식  | 의미                                       | 사용 대상            |
| ---------- | ------------------------------------------ | -------------------- |
| `==`       | 기본 타입은 값 비교, 참조 타입은 주소 비교 | 기본 타입, 참조 타입 |
| `equals()` | 객체의 내용 비교                           | String 등 참조 타입  |

## 5. 문자열 작성 방법

### 일반 문자열

```java
String s1 = "안녕하세요\n";
```

`\n`은 줄바꿈을 의미하는 제어 문자이다.

### Text Block

Java에서는 여러 줄 문자열을 작성할 때 Text Block을 사용할 수 있다.

```java
String s2 = """
안녕하세요
자바입니다.
""";
```

Text Block은 여러 줄 문자열을 더 읽기 쉽게 작성할 수 있게 해준다.

## 6. Wrapper Class

Wrapper Class는 기본 타입을 객체처럼 사용할 수 있도록 제공되는 클래스이다.

| 기본 타입 | Wrapper Class |
| --------- | ------------- |
| `byte`    | `Byte`        |
| `short`   | `Short`       |
| `char`    | `Character`   |
| `int`     | `Integer`     |
| `long`    | `Long`        |
| `float`   | `Float`       |
| `double`  | `Double`      |
| `boolean` | `Boolean`     |

예전 방식:

```java
Integer a1 = Integer.valueOf(200);
```

Auto Boxing:

```java
Integer a2 = 200;
```

Unboxing:

```java
int a3 = a2;
```

정리하면 다음과 같다.

- Boxing: 기본 타입을 Wrapper Class 객체로 변환
- Unboxing: Wrapper Class 객체를 기본 타입으로 변환
- Auto Boxing: Java가 자동으로 Boxing 처리
- Auto Unboxing: Java가 자동으로 Unboxing 처리

## 7. 변수의 범위

메서드 안에서 선언된 변수는 지역 변수이다.

```java
public void test() {
    int number = 10;
}
```

지역 변수는 선언만 하고 초기화하지 않으면 사용할 수 없다.

```java
public void test() {
    int number;

    // System.out.println(number); // 컴파일 오류
}
```

반면 필드는 기본값으로 자동 초기화된다.

```java
public class Person {
    int age;        // 0
    boolean active; // false
    String name;   // null
}
```

## 8. 형 변환

형 변환은 크게 자동 형 변환과 강제 형 변환으로 나뉜다.

## 8-1. 자동 형 변환

작은 타입의 값을 큰 타입에 저장할 때는 자동 형 변환이 일어난다.

```java
byte v1 = 10;
int v2 = v1;
long v3 = v2;
double v4 = v3;
```

정수 연산에서는 `byte`, `short`, `char` 타입이 `int`로 변환되어 연산된다.

```java
int result1;
byte result2;

byte x = 10;
byte y = 120;

result1 = x + y;
result2 = (byte)(x + y);

System.out.println(result1); // 130
System.out.println(result2); // -126
```

`x + y`의 결과는 `int` 타입이다.  
`130`을 `byte`로 강제 변환하면 byte의 범위를 초과하므로 값이 예상과 다르게 나온다.

---

## 8-2. 강제 형 변환

큰 타입의 값을 작은 타입에 저장하려면 강제 형 변환이 필요하다.

```java
int v1;
long v2 = 10000000000L;
float v3 = 3.14f;
boolean v4 = true;

v1 = (int) v2;
v1 = (int) v3;

// v1 = (int) v4; // boolean은 다른 타입으로 형 변환할 수 없다.
```

강제 형 변환은 값의 손실이 발생할 수 있다.

- 큰 정수를 작은 타입으로 변환하면 값이 손실될 수 있다.
- 실수를 정수로 변환하면 소수점 이하가 버려진다.
- `boolean`은 다른 기본 타입으로 변환할 수 없다.

## 9. String을 기본 타입으로 변환

문자열로 저장된 숫자는 Wrapper Class의 `parse` 메서드를 사용해 기본 타입으로 변환할 수 있다.

```java
String s1 = "100";

int v1 = Integer.parseInt(s1) + 100;
long v2 = Long.parseLong(s1) + 200L;
byte v3 = (byte)(Byte.parseByte(s1) + 1);
short v4 = (short)(Short.parseShort(s1) + 1);
float v5 = Float.parseFloat(s1) + 3.14f;
double v6 = Double.parseDouble(s1) + 3.14;
```

문자열이 숫자로 변환할 수 없는 형태이면 오류가 발생한다.

```java
String s2 = "abc";

// int value = Integer.parseInt(s2); // NumberFormatException 발생
```

## 정리

- Java의 `.java` 파일에는 여러 클래스를 정의할 수 있지만, `public` 클래스는 하나만 선언할 수 있다.
- Java 클래스는 필드, 생성자, 메서드, 초기화 블록, 내부 클래스로 구성될 수 있다.
- Java의 기본 타입은 정수, 실수, 논리 타입으로 나뉜다.
- `String`은 기본 타입이 아니라 문자열을 다루는 클래스 타입이다.
- 기본 타입은 `==`으로 값을 비교하지만, `String`의 내용 비교는 `equals()`를 사용해야 한다.
- Wrapper Class는 기본 타입을 객체처럼 사용할 수 있게 해준다.
- 지역 변수는 초기화하지 않으면 사용할 수 없다.
- 형 변환은 자동 형 변환과 강제 형 변환으로 나뉜다.
- 문자열을 숫자로 바꿀 때는 `Integer.parseInt()` 같은 메서드를 사용한다.
