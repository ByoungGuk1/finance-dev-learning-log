## 2. Java 출력 방식

Java에서 콘솔 출력은 주로 `System.out`을 사용한다.

```java
System.out.print(false);
System.out.print('A');
System.out.print("Hello");
System.out.println("---------------");
System.out.print("출력 후 줄바꿈\n");
```

## 2-1. print()

`print()`는 출력 후 줄바꿈을 하지 않는다.

```java
System.out.print("Hello");
System.out.print("Java");
```

출력 결과:

```text
HelloJava
```

## 2-2. `println()`

`println()`은 출력 후 줄바꿈을 한다.

```java
System.out.println("Hello");
System.out.println("Java");
```

출력 결과:

```text
Hello
Java
```

## 2-3. `printf()`

`printf()`는 형식 지정자를 사용해 값을 원하는 형태로 출력한다.

```java
System.out.printf(
    "format에 맞추어 출력\n정수 값 : %-5d\n실수 값 : %.2f\n문자 값 : %10s\n",
    100,
    3.141592,
    "자바"
);
```

주요 형식 지정자:

| 형식 지정자 | 의미                          |
| ----------- | ----------------------------- |
| `%d`        | 정수                          |
| `%f`        | 실수                          |
| `%s`        | 문자열                        |
| `%c`        | 문자                          |
| `%.2f`      | 소수점 둘째 자리까지 출력     |
| `%10s`      | 전체 10칸 확보 후 문자열 출력 |
| `%-5d`      | 전체 5칸 확보 후 왼쪽 정렬    |

## 3. Java 입력 방식

Java에서 콘솔 입력은 `System.in` 또는 `Scanner`를 사용할 수 있다.

---

## 3-1. `System.in.read()`

`System.in.read()`는 입력된 데이터를 1 byte 단위로 읽는다.

```java
InputStream is = System.in;
int data = is.read();

System.out.printf("입력 결과 : %s\n", (char) data);
```

입력값은 정수로 반환되기 때문에 문자로 출력하려면 형 변환이 필요하다.

```java
(char) data
```

주의할 점:

```java
is.close();
```

`System.in`을 닫으면 이후 같은 프로그램에서 다시 입력을 받을 수 없다.  
따라서 여러 입력 예제를 한 번에 실행할 때는 `System.in`이나 `Scanner`를 무조건 닫지 않는 것이 좋다.

---

## 3-2. `Scanner`

`Scanner`는 Java에서 콘솔 입력을 쉽게 처리할 수 있게 해주는 클래스이다.

```java
Scanner sc = new Scanner(System.in);

System.out.print("이름을 입력하세요 >>> ");
String name = sc.nextLine();

System.out.print("나이를 입력하세요 >>> ");
int age = Integer.parseInt(sc.nextLine());

System.out.printf("반갑습니다. %s님\n나이는 %d\n", name, age);
```

`Scanner`를 사용할 때 자주 쓰는 메서드는 다음과 같다.

| 메서드         | 설명                    |
| -------------- | ----------------------- |
| `next()`       | 공백 전까지 문자열 입력 |
| `nextLine()`   | 한 줄 전체 입력         |
| `nextInt()`    | 정수 입력               |
| `nextDouble()` | 실수 입력               |

---

## 3-3. `next()`와 `nextLine()` 차이

```java
String name = sc.next();
sc.nextLine();
int age = sc.nextInt();
```

`next()`는 공백 전까지만 읽는다.  
`nextLine()`은 엔터까지 포함한 한 줄을 읽는다.

`nextInt()`를 사용한 뒤 `nextLine()`을 바로 사용하면 남아 있는 엔터 때문에 입력이 건너뛰어질 수 있다.

그래서 필요할 때는 중간에 `sc.nextLine()`으로 버퍼를 비워준다.

```java
int age = sc.nextInt();
sc.nextLine(); // 남아 있는 엔터 제거
String address = sc.nextLine();
```

## 4. 필드와 지역 변수의 초기화 차이

클래스 필드는 자동으로 기본값으로 초기화된다.

```java
static int b;
static String s;
static Scanner sc2;
static char ch;
```

필드의 기본값:

| 타입      | 기본값  |
| --------- | ------- |
| 정수 타입 | `0`     |
| 실수 타입 | `0.0`   |
| `boolean` | `false` |
| `char`    | ` `     |
| 참조 타입 | `null`  |

예시:

```java
System.out.println(b);   // 0
System.out.println(s);   // null
System.out.println(sc2); // null
System.out.println("*" + ch + "*"); // * *
```

반면 지역 변수는 자동 초기화되지 않는다.

```java
public void method() {
    int number;

    // System.out.println(number); // 컴파일 오류
}
```

지역 변수는 반드시 직접 초기화한 뒤 사용해야 한다.

## 5. 변수명 작성 규칙

Java 변수명에는 문자, 숫자, `_`, `$`를 사용할 수 있다.

```java
int _v1 = 1;
int $v2 = 2;
```

하지만 실무에서는 `_`나 `$`로 시작하는 변수명은 일반적으로 권장하지 않는다.  
보통은 의미가 명확한 camelCase를 사용한다.

```java
int userAge = 20;

```

변수 선언의 구성:

```java
int a = 10;
```

| 요소  | 의미   |
| ----- | ------ |
| `int` | 타입   |
| `a`   | 변수명 |
| `10`  | 리터럴 |

## 6. 문자열과 문자 처리

문자열에서 특정 위치의 문자를 가져올 때는 `charAt()`을 사용한다.

```java
String s = "Hello";
char result = s.charAt(0);

System.out.println(result); // H
```

문자열을 문자 배열로 변환할 때는 `toCharArray()`를 사용한다.

```java
char[] arr = s.toCharArray();
System.out.println(Arrays.toString(arr));
```

출력 결과:

```text
[H, e, l, l, o]
```

공백 문자도 하나의 문자이다.

```java
char ch = ' ';
System.out.println(ch);
```

## 7. 산술 연산자와 예외 처리

정수 나눗셈에서는 몫과 나머지를 구할 수 있다.

```java
int su1 = 10;
int su2 = 3;

System.out.println("몫 : " + su1 / su2);
System.out.println("나머지 : " + su1 % su2);
```

출력 결과:

```text
몫 : 3
나머지 : 1
```

정수를 `0`으로 나누면 `ArithmeticException`이 발생한다.

```java
try {
    System.out.println(10 / 0);
} catch (ArithmeticException e) {
    System.err.println(e.getMessage());
}
```

예외 처리를 하면 프로그램이 바로 중단되지 않고 이후 흐름을 계속 진행할 수 있다.

## 8. 실수 연산의 Infinity와 NaN

정수에서 `0`으로 나누면 예외가 발생하지만, 실수에서는 예외가 발생하지 않고 특수한 값이 나올 수 있다.

```java
double data = 10;
double num = 0.0;

System.out.println(data / num); // Infinity
System.out.println(data % num); // NaN
```

## 8-1. Infinity 확인

`Double.isInfinite()`으로 무한대 여부를 확인할 수 있다.

```java
if (Double.isInfinite(data / num)) {
    System.out.println("무한대입니다. 값을 다시 확인해 주세요.");
} else {
    System.out.println(data / num);
}
```

## 8-2. NaN 확인

`Double.isNaN()`으로 숫자가 아닌 값인지 확인할 수 있다.

```java
if (Double.isNaN(data % num)) {
    System.out.println("NaN 오류");
} else {
    System.out.println(data % num);
}
```

정리:

| 결과       | 의미                      |
| ---------- | ------------------------- |
| `Infinity` | 무한대                    |
| `NaN`      | Not a Number, 숫자가 아님 |

## 9. 문자열 비교

문자열은 참조 타입이다.  
따라서 `==`은 문자열의 내용이 아니라 참조 주소를 비교한다.

```java
String s1 = "가나다";
String s2 = "가나다";

System.out.println(s1 == s2);
```

문자열 리터럴은 문자열 상수 풀에 저장되기 때문에 위 코드는 `true`가 나올 수 있다.

하지만 문자열의 실제 값을 비교할 때는 반드시 `equals()`를 사용해야 한다.

```java
String s1 = "가나다";
s1 += "라";

System.out.println(s1 == "가나다라");        // false
System.out.println(s1.equals("가나다라"));   // true
```

정리:

| 비교 방식  | 의미             |
| ---------- | ---------------- |
| `==`       | 참조 주소 비교   |
| `equals()` | 문자열 내용 비교 |

문자열 비교는 원칙적으로 `equals()`를 사용한다.

## 10. 증감 연산자

증감 연산자는 변수의 값을 1 증가시키거나 감소시킨다.

```java
int a = 10;

a++;
++a;
```

## 10-1. 전위 증가

```java
System.out.println(++a);
```

값을 먼저 증가시키고 사용한다.

## 10-2. 후위 증가

```java
System.out.println(a++);
```

값을 먼저 사용하고 나중에 증가시킨다.

예시:

```java
int a = 10;

a++;
++a;

System.out.println(++a); // 13
System.out.println(a++); // 13
System.out.println(a);   // 14
```

## 11. 논리 연산자와 단축 평가

논리 연산자는 조건식을 연결할 때 사용한다.

| 연산자 | 의미                     |
| ------ | ------------------------ |
| `&&`   | AND, 모두 참이면 true    |
| `\|\|` | OR, 하나라도 참이면 true |
| `&`    | AND, 양쪽 모두 검사      |
| `\|`   | OR, 양쪽 모두 검사       |

---

## 11-1. `&&`

`&&`는 앞 조건이 `false`이면 뒤 조건을 검사하지 않는다.  
이를 단축 평가 short-circuit evaluation라고 한다.

```java
int a = 10;

System.out.println(a > 20 && ++a > 10);
System.out.println(a);
```

`a > 20`이 `false`이므로 `++a > 10`은 실행되지 않는다.

---

## 11-2. `&`

`&`는 앞 조건이 `false`여도 뒤 조건을 검사한다.

```java
int a = 10;

System.out.println(a > 20 & ++a > 10);
System.out.println(a);
```

앞 조건이 `false`여도 `++a`가 실행된다.

---

## 11-3. `||`

`||`는 앞 조건이 `true`이면 뒤 조건을 검사하지 않는다.

```java
int a = 10;

System.out.println(a < 20 || ++a > 10);
System.out.println(a);
```

`a < 20`이 `true`이므로 `++a > 10`은 실행되지 않는다.

---

## 11-4. `|`

`|`는 앞 조건이 `true`여도 뒤 조건을 검사한다.

```java
int a = 10;

System.out.println(a < 20 | ++a > 10);
System.out.println(a);
```

앞 조건이 `true`여도 `++a`가 실행된다.

정리:

| 연산자 | 특징                                 |
| ------ | ------------------------------------ |
| `&&`   | AND, 앞이 false면 뒤를 실행하지 않음 |
| `&`    | AND, 양쪽 모두 실행                  |
| `\|\|` | OR, 앞이 true면 뒤를 실행하지 않음   |
| `\|`   | OR, 양쪽 모두 실행                   |

실무에서는 조건문에서 대부분 `&&`, `||`를 사용한다.  
`&`, `|`는 비트 연산 또는 양쪽 조건을 반드시 평가해야 하는 경우에 사용한다.

## 12. 비트 연산자

비트 연산자는 정수를 2진수 단위로 계산한다.

예시:

```java
int read = 0b100;
int write = 0b010;

System.out.println(Integer.toBinaryString(read | write));
System.out.println(Integer.toBinaryString(read & write));
```

## 12-1. OR 연산

```java
read | write
```

```text
100
010
---
110
```

둘 중 하나라도 1이면 결과가 1이다.

## 12-2. AND 연산

```java
read & write
```

```text
100
010
---
000
```

둘 다 1일 때만 결과가 1이다.

비트 연산은 권한 처리 같은 곳에서 사용할 수 있다.

```java
int read = 0b100;
int write = 0b010;
int execute = 0b001;

int permission = read | write;
```

위 코드는 읽기와 쓰기 권한을 함께 가진 상태를 의미한다.

## 13. 대입 연산자

대입 연산자는 변수에 값을 저장하거나 기존 값에 연산을 적용한다.

```java
int a = 10;

a++;
++a;
a += 1;

System.out.println(a);
```

`a += 1`은 다음 코드와 같은 의미이다.

```java
a = a + 1;
```

## 14. 삼항 연산자

삼항 연산자는 조건에 따라 다른 값을 선택할 때 사용한다.

```java
int score = 99;
String message;

if (score >= 90) {
    message = "합격";
} else {
    message = "불합격";
}

System.out.println(message);
```

위 코드는 삼항 연산자로 줄일 수 있다.

```java
message = score >= 90 ? "합격" : "불합격";
System.out.println(message);
```

구조:

```java
조건식 ? 참일 때 값 : 거짓일 때 값
```

삼항 연산자는 간단한 조건에만 사용하는 것이 좋다.  
조건이 복잡하면 `if-else`가 더 읽기 쉽다.

## 어제 내용 복습

### 1. 클래스와 파일명

하나의 `.java` 파일 안에는 여러 클래스를 선언할 수 있다.

```java
class AA {
}
```

하지만 `public` 클래스는 하나만 선언할 수 있다.

```java
public class ReviewDay01 {
}
```

`public` 클래스가 있는 경우 파일명은 `public` 클래스명과 같아야 한다.

```text
ReviewDay01.java
```

---

### 2. 기본 타입과 Wrapper Class

Java의 기본 타입은 값을 저장하고 읽고 계산하고 비교하는 데 사용된다.

```java
int i = 10;
String s = Integer.toBinaryString(i);
```

`Integer.toBinaryString()`은 정수를 2진수 문자열로 변환한다.

```java
System.out.println(Integer.toBinaryString(10)); // 1010
```

기본 타입과 Wrapper Class는 다음과 같이 대응된다.

| 기본 타입 | Wrapper Class |
| --------- | ------------- |
| `byte`    | `Byte`        |
| `short`   | `Short`       |
| `char`    | `Character`   |
| `int`     | `Integer`     |
| `long`    | `Long`        |
| `float`   | `Float`       |
| `double`  | `Double`      |
| `boolean` | `Boolean`     |

---

### 3. 형 변환

작은 타입의 값을 큰 타입에 저장할 때는 자동 형 변환이 일어난다.

```java
int v1;
char v2 = 'A';

v1 = v2;
System.out.println(v1); // 65
```

`char`는 내부적으로 문자 코드를 가지므로 `int`로 변환할 수 있다.

큰 타입의 값을 작은 타입에 저장할 때는 강제 형 변환이 필요하다.

```java
v2 = (char) v1;
System.out.println(v2); // A
```

강제 형 변환은 데이터 손실이 발생할 수 있다.

---

### 4. 정수 연산의 기본 타입

`byte`, `short`, `char`는 연산 시 기본적으로 `int`로 변환된다.

```java
byte v1 = 10;
byte v2 = 20;

int result1 = v1 + v2;
byte result2 = (byte)(v1 + v2);
```

`v1 + v2`의 결과는 `byte`가 아니라 `int`이다.  
따라서 `byte` 변수에 저장하려면 강제 형 변환이 필요하다.

```java
byte result2 = (byte)(v1 + v2);
```

---

### 5. 기본 타입을 문자열로 변환

기본 타입 값을 문자열로 변환하는 방법은 여러 가지가 있다.

```java
int v1 = 100;

String v2 = v1 + "";
String v3 = String.valueOf(v1);
```

둘 다 문자열로 변환되지만, 명확한 의도를 표현하려면 `String.valueOf()`를 사용하는 것이 좋다.

```java
String v3 = String.valueOf(v1);
```

차이:

```java
System.out.println(v1 + 200); // 300
System.out.println(v2 + 200); // 100200
System.out.println(v3 + 200); // 100200
```

숫자끼리 더하면 산술 연산이 되고, 문자열이 포함되면 문자열 연결이 된다.

---

### 6. Auto Boxing과 Auto Unboxing

기본 타입을 Wrapper Class로 자동 변환하는 것을 Auto Boxing이라고 한다.

```java
Integer v2 = 200;
```

Wrapper Class 객체가 연산 등에 사용될 때 기본 타입 값으로 자동 변환되는 것을 Auto Unboxing이라고 한다.

```java
System.out.println(v2 + 200 == 400);
```

실제로는 `Integer` 객체의 값을 꺼내서 연산한다.

```java
System.out.println(v2.intValue() + 200 == 400);
```

정수를 16진수 문자열로 변환할 수도 있다.

```java
System.out.println(Integer.toHexString(v2));
```

### 7. static 필드와 지역 변수의 범위

static 필드는 클래스에 소속된 변수이다.

```java
static String model = "ABC모델";
static int price = 1000;
```

같은 클래스의 static 메서드에서 바로 접근할 수 있다.

```java
public static void method1() {
    System.out.println("method1-model" + model);
    System.out.println("method1-price" + price);
}
```

지역 변수는 메서드가 호출될 때 생성되고, 메서드가 종료되면 사라진다.

```java
public static void method1() {
    int v1 = 100;
    System.out.println(v1 + 200);
}
```

블록 안에서 선언한 변수는 블록 밖에서 접근할 수 없다.

```java
if (v1 >= 100) {
    char ch = 'A';
    System.out.println("지역변수: " + ch);
}

// System.out.println(ch); // 컴파일 오류
```

정리:

| 변수 종류   | 선언 위치              | 특징                  |
| ----------- | ---------------------- | --------------------- |
| 필드        | 클래스 내부            | 자동 초기화됨         |
| static 필드 | 클래스 내부 + `static` | 클래스 단위로 공유    |
| 지역 변수   | 메서드 내부            | 직접 초기화해야 함    |
| 블록 변수   | `{}` 내부              | 블록 밖에서 접근 불가 |

## 정리

- `print()`는 줄바꿈 없이 출력하고, `println()`은 출력 후 줄바꿈한다.
- `printf()`는 형식 지정자를 사용해 출력 형식을 제어한다.
- `System.in.read()`는 1 byte 단위 입력을 처리한다.
- `Scanner`는 콘솔 입력을 쉽게 처리할 수 있게 해준다.
- 필드는 자동 초기화되지만 지역 변수는 직접 초기화해야 한다.
- 정수를 `0`으로 나누면 `ArithmeticException`이 발생한다.
- 실수 연산에서는 `Infinity`, `NaN`이 발생할 수 있다.
- 문자열 내용 비교는 `equals()`를 사용해야 한다.
- `++a`는 먼저 증가 후 사용하고, `a++`는 먼저 사용 후 증가한다.
- `&&`, `||`는 단축 평가를 수행한다.
- `&`, `|`는 조건식에서는 양쪽을 모두 평가하고, 정수에서는 비트 연산자로 사용된다.
- 삼항 연산자는 간단한 조건 분기에 사용할 수 있다.
- `byte`, `short`, `char`는 연산 시 `int`로 변환된다.
- `String.valueOf()`를 사용하면 기본 타입을 명확하게 문자열로 변환할 수 있다.
- static 필드는 클래스 단위로 공유되고, 지역 변수는 메서드 실행 중에만 존재한다.
