## 2. 이번 주 핵심 흐름

이번 주는 JavaScript 기본 문법에서 시작해 서버와 비동기 통신하는 Ajax 흐름까지 연결했다.

```text
DOM 조작
→ 이벤트 처리
→ 배열/객체 데이터 가공
→ 비동기 요청
→ Fetch API
→ jQuery DOM 조작
→ jQuery Ajax
→ Servlet API와 JSON 연동
```

## 3. JavaScript 핵심

JavaScript에서는 화면 요소와 데이터를 함께 다룬다.

이번 주 주요 개념은 다음과 같다.

- DOM 선택과 조작
- 이벤트 연결
- 배열 메서드 `map`, `filter`, `reduce`
- 객체와 구조분해
- Spread 문법
- localStorage

특히 배열과 객체를 다루는 방식은 서버에서 받은 JSON 데이터를 화면에 렌더링할 때 중요하다.

---

## 4. 비동기 처리

비동기 처리는 시간이 걸리는 작업을 기다리는 동안 브라우저가 멈추지 않도록 하기 위한 방식이다.

```javascript
const getData = async (url) => {
    const res = await fetch(url);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return res.json();
};
```

비동기 처리에서 중요한 점은 요청이 성공했는지 확인하고, 응답 데이터를 어떤 형태로 사용할지 명확히 하는 것이다.

## 5. jQuery 핵심

jQuery는 DOM 선택, 이벤트 처리, Ajax 요청을 짧게 작성할 수 있게 해준다.

```javascript
$("#btn").on("click", function () {
    console.log("click");
});
```

동적으로 생성되는 요소에는 이벤트 위임이 중요하다.

```javascript
$("#empBody").on("click", ".btnEdit", showDetail);
```

## 6. Ajax와 Servlet 연동

Ajax 실습의 핵심은 페이지 전체 이동 없이 서버에서 JSON을 받아 화면 일부만 다시 그리는 것이다.

```text
브라우저 이벤트
→ $.ajax()
→ Servlet API
→ Service
→ DAO
→ DB
→ JSON 응답
→ renderData()
```

이 흐름은 이후 Spring Boot REST API와 프론트엔드 연동 구조로 이어진다.

사원 관리 실습에서는 다음 흐름을 구현했다.

## 9. 면접 질문과 답변

### Ajax는 무엇인가요?

Ajax는 페이지 전체를 새로고침하지 않고 JavaScript로 서버와 데이터를 주고받아 화면 일부만 갱신하는 방식이다.

### 이벤트 위임은 왜 사용하나요?

동적으로 생성된 요소는 초기 이벤트 등록 시점에 존재하지 않을 수 있다. 부모 요소에 이벤트를 등록하면 나중에 추가된 자식 요소에도 이벤트를 처리할 수 있다.

### Fetch API와 jQuery Ajax는 어떤 차이가 있나요?

Fetch API는 브라우저 내장 API이고 Promise 기반이다. jQuery Ajax는 jQuery가 제공하는 Ajax 유틸리티로, 설정과 콜백 기반 처리가 간단하다.
