## 3. HTML

HTML은 웹 페이지의 구조를 작성한다.

주요 내용은 다음과 같다.

- 문서 기본 구조
- 제목, 문단, 목록, 표
- 이미지와 링크
- form 입력 양식
- 시맨틱 태그
- 접근성 관점의 label 사용

`form`에서는 `name` 속성이 서버로 전달되는 파라미터 이름이 된다.
이후 Servlet/JSP에서 `request.getParameter()`로 값을 읽기 때문에 HTML 입력 이름과 서버 파라미터 이름이 맞아야 한다.

## 4. CSS

CSS는 화면 스타일과 레이아웃을 담당한다.

이번 주 핵심 CSS 개념은 다음과 같다.

- 선택자
- 우선순위
- 박스 모델
- display
- position
- flexbox
- grid
- transition / animation

CSS는 단순 색상 변경보다 레이아웃 계산이 중요하다.
특히 `box-sizing`, `display`, `position`은 화면이 의도와 다르게 보일 때 우선 확인해야 한다.

## 5. JavaScript 시작

JavaScript는 웹 페이지의 동작을 담당한다.

이번 주에는 다음 내용을 시작했다.

- 변수와 자료형
- 조건문과 반복문
- 함수
- 객체
- DOM 선택
- 이벤트 연결
- `window.onload`

`window.onload`는 HTML 요소가 로드된 뒤 JS를 실행하기 위해 사용한다.
DOM을 찾는 시점이 맞지 않으면 `null` 오류가 발생할 수 있다.

## 6. Servlet/Tomcat 메모

Web 수업 시작과 함께 Tomcat 배포 위치와 Servlet Mapping 오류도 정리했다.

Servlet Mapping이 잘못되면 요청 URL과 Servlet 클래스가 연결되지 않는다.
또 Eclipse에서 작성한 파일과 Tomcat에 배포된 파일 위치가 다르기 때문에, 수정 내용이 반영되지 않을 때 배포 위치와 서버 상태를 확인해야 한다.

## 8. 면접 질문과 답변

### HTML의 `id`와 `name`은 어떤 차이가 있나요?

`id`는 문서 내 요소를 식별하기 위한 값이고, `name`은 form 데이터를 서버로 보낼 때 파라미터 이름으로 사용된다.

### CSS에서 Flexbox와 Grid는 어떻게 구분해서 사용하나요?

Flexbox는 주로 한 방향 배치에 적합하고, Grid는 행과 열을 모두 다루는 2차원 배치에 적합하다.

### `window.onload`를 사용하는 이유는 무엇인가요?

HTML 요소가 모두 로드된 뒤 JavaScript를 실행하기 위해 사용한다. 요소가 만들어지기 전에 JS가 실행되면 DOM 선택 결과가 `null`이 될 수 있다.
