## 2. Java 파일과 클래스

하나의 `.java` 파일 안에는 여러 클래스를 선언할 수 있다.

다만 `public` 클래스는 하나만 선언할 수 있고, `public` 클래스가 있다면 파일명은 해당 클래스명과 같아야 한다.

```java
public class Main {
}

class SubClass {
}
```

위 코드의 파일명은 `Main.java`가 되어야 한다.

이번 주에 다시 확인한 내용:

- `.java` 파일에는 여러 클래스 선언 가능
- `public` 클래스는 하나만 가능
- `public` 클래스명과 파일명은 일치해야 함

## 3. 클래스 구성 요소

Java 클래스는 다음 요소들로 구성될 수 있다.

| 구성 요소      | 설명                                     |
| -------------- | ---------------------------------------- |
| field          | 클래스에 선언되는 변수                   |
| constructor    | 객체 생성 시 호출되는 생성자             |
| method         | 클래스 내부에 정의되는 함수              |
| instance block | 객체 생성 시 실행되는 초기화 블록        |
| static block   | 클래스 로딩 시 실행되는 정적 초기화 블록 |
| inner class    | 클래스 내부에 선언되는 클래스            |

기본 구조:

```java
public class Person {
    String name;

    public Person(String name) {
        this.name = name;
    }

    public void printName() {
        System.out.println(name);
    }

    {
        System.out.println("instance block");
    }

    static {
        System.out.println("static block");
    }

    class Address {
    }
}
```

## 4. 변수 타입

Java의 변수 타입은 크게 기본 타입과 참조 타입으로 나뉜다.

## 4-1. 기본 타입

기본 타입은 값을 직접 저장한다.

| 분류 | 타입                                   |
| ---- | -------------------------------------- |
| 정수 | `byte`, `short`, `char`, `int`, `long` |
| 실수 | `float`, `double`                      |
| 논리 | `boolean`                              |

정수 리터럴의 기본 타입은 `int`이고, 실수 리터럴의 기본 타입은 `double`이다.

```java
int number = 100;
long bigNumber = 10000000000L;

float f = 3.14f;
double d = 3.14;

boolean active = true;
```

`long`은 큰 정수 리터럴에 `L`을 붙이고, `float`은 실수 리터럴에 `f`를 붙인다.

---

## 4-2. 참조 타입

`String`은 기본 타입이 아니라 참조 타입이다.

```java
String name = "Java";
```

`String`은 `java.lang.String` 클래스이며, 기본 타입처럼 자주 사용되지만 실제로는 객체를 참조한다.

---

## 5. String 비교

기본 타입은 `==`으로 값을 비교한다.

```java
int a = 100;
int b = 100;

System.out.println(a == b); // true
```

하지만 `String`은 참조 타입이므로 `==`은 주소를 비교한다.  
문자열의 실제 내용 비교는 `equals()`를 사용해야 한다.

```java
String s1 = "자바";
String s2 = "자바";
String s3 = new String("자바");

System.out.println(s1 == s2);      // true
System.out.println(s1 == s3);      // false
System.out.println(s1.equals(s3)); // true
```

정리:

| 비교 방식  | 의미                                       |
| ---------- | ------------------------------------------ |
| `==`       | 기본 타입은 값 비교, 참조 타입은 주소 비교 |
| `equals()` | 객체의 내용 비교                           |

문자열 값 비교는 `==`가 아니라 `equals()`를 기본으로 생각해야 한다.

## 6. Wrapper Class

Wrapper Class는 기본 타입을 객체처럼 사용할 수 있게 해주는 클래스이다.

| 기본 타입 | Wrapper Class |
| --------- | ------------- |
| `byte`    | `Byte`        |
| `short`   | `Short`       |
| `char`    | `Character`   |
| `int`     | `Integer`     |
| `long`    | `Long`        |
| `float`   | `Float`       |
| `double`  | `Double`      |
| `boolean` | `Boolean`     |

Auto Boxing:

```java
Integer number = 200;
```

Auto Unboxing:

```java
int result = number + 100;
```

Wrapper Class는 문자열을 기본 타입으로 바꿀 때도 사용한다.

```java
String value = "100";

int intValue = Integer.parseInt(value);
long longValue = Long.parseLong(value);
double doubleValue = Double.parseDouble(value);
```

문자열이 숫자로 변환할 수 없는 값이면 `NumberFormatException`이 발생한다.

## 7. 변수의 범위와 초기화

필드는 자동으로 기본값으로 초기화된다.

```java
class Example {
    int number;      // 0
    boolean active;  // false
    String name;     // null
    char ch;         // '\u0000' 널 문자
}
```

지역 변수는 자동 초기화되지 않는다.

```java
public void method() {
    int number;

    // System.out.println(number); // 컴파일 오류
}
```

정리:

| 변수 종류   | 선언 위치              | 초기화 여부       |
| ----------- | ---------------------- | ----------------- |
| 필드        | 클래스 내부            | 자동 초기화       |
| static 필드 | 클래스 내부 + `static` | 자동 초기화       |
| 지역 변수   | 메서드 내부            | 직접 초기화 필요  |
| 블록 변수   | `{}` 내부              | 블록 밖 접근 불가 |

`char`의 기본값은 널 문자 `'\u0000'`이다.

## 8. 형 변환

형 변환은 자동 형 변환과 강제 형 변환으로 나뉜다.

## 8-1. 자동 형 변환

작은 타입의 값을 큰 타입에 저장할 때는 자동 형 변환이 일어난다.

```java
byte b = 10;
int i = b;
long l = i;
double d = l;
```

`char`도 내부적으로 문자 코드를 가지므로 `int`로 변환할 수 있다.

```java
char ch = 'A';
int code = ch;

System.out.println(code); // 65
```

---

## 8-2. 강제 형 변환

큰 타입의 값을 작은 타입에 저장하려면 명시적인 형 변환이 필요하다.

```java
long l = 10000000000L;
int i = (int) l;
```

강제 형 변환은 값 손실이 발생할 수 있다.

```java
float f = 3.14f;
int number = (int) f;

System.out.println(number); // 3
```

실수를 정수로 변환하면 소수점 이하가 버려진다.

---

## 8-3. 정수 연산의 기본 타입

`byte`, `short`, `char`는 연산 시 기본적으로 `int`로 변환된다.

```java
byte x = 10;
byte y = 120;

int result1 = x + y;
byte result2 = (byte)(x + y);

System.out.println(result1); // 130
System.out.println(result2); // -126
```

`x + y`의 결과는 `int`이다.  
`130`을 `byte`로 강제 변환하면 byte 범위를 초과하므로 예상과 다른 값이 나온다.

## 9. 출력 방식

콘솔 출력은 `System.out`을 사용한다.

```java
System.out.print("Hello");
System.out.println("Java");
System.out.printf("정수: %d, 실수: %.2f\n", 100, 3.141592);
```

| 메서드      | 특징                      |
| ----------- | ------------------------- |
| `print()`   | 출력 후 줄바꿈 없음       |
| `println()` | 출력 후 줄바꿈            |
| `printf()`  | 형식 지정자를 사용한 출력 |

주요 형식 지정자:

| 형식 지정자 | 의미                      |
| ----------- | ------------------------- |
| `%d`        | 정수                      |
| `%f`        | 실수                      |
| `%s`        | 문자열                    |
| `%c`        | 문자                      |
| `%.2f`      | 소수점 둘째 자리까지 출력 |

## 10. 입력 방식

콘솔 입력은 `System.in` 또는 `Scanner`를 사용할 수 있다.

## 10-1. System.in.read()

`System.in.read()`는 입력 스트림에서 1 byte를 읽고, 그 값을 `int`로 반환한다.

```java
int data = System.in.read();
System.out.println((char) data);
```

영문자나 숫자처럼 1 byte로 표현되는 문자는 `(char)`로 확인하기 쉽다.  
한글처럼 여러 byte로 표현되는 문자는 깨질 수 있다.

---

## 10-2. Scanner

`Scanner`는 콘솔 입력을 쉽게 처리할 수 있게 해준다.

```java
Scanner sc = new Scanner(System.in);

String name = sc.nextLine();
int age = Integer.parseInt(sc.nextLine());
```

자주 사용한 메서드:

| 메서드         | 설명             |
| -------------- | ---------------- |
| `next()`       | 공백 전까지 입력 |
| `nextLine()`   | 한 줄 전체 입력  |
| `nextInt()`    | 정수 입력        |
| `nextDouble()` | 실수 입력        |

`nextInt()` 뒤에 `nextLine()`을 바로 사용하면 남아 있는 엔터 때문에 입력이 건너뛰어질 수 있다.

```java
int age = sc.nextInt();
sc.nextLine(); // 남아 있는 엔터 제거
String address = sc.nextLine();
```

여러 입력 예제를 한 번에 실행할 때는 입력 스트림을 닫는 위치를 조심해야 한다.

## 11. 예외 처리

정수를 `0`으로 나누면 `ArithmeticException`이 발생한다.

```java
try {
    System.out.println(10 / 0);
} catch (ArithmeticException e) {
    System.err.println(e.getMessage());
}
```

예외 처리를 하면 프로그램이 바로 중단되지 않고 이후 흐름을 계속 진행할 수 있다.

`System.in.read()`는 `IOException`이 발생할 수 있으므로 예외 처리가 필요하다.

```java
try {
    int data = System.in.read();
    System.out.println(data);
} catch (IOException e) {
    e.printStackTrace();
}
```

## 12. 실수 연산의 Infinity와 NaN

정수에서 `0`으로 나누면 예외가 발생하지만, 실수에서는 예외가 아니라 특수한 값이 나올 수 있다.

```java
double data = 10;
double num = 0.0;

System.out.println(data / num); // Infinity
System.out.println(data % num); // NaN
```

확인은 다음 메서드를 사용한다.

```java
Double.isInfinite(data / num);
Double.isNaN(data % num);
```

| 결과       | 의미         |
| ---------- | ------------ |
| `Infinity` | 무한대       |
| `NaN`      | Not a Number |

## 13. 증감 연산자

증감 연산자는 값을 1 증가시키거나 감소시킨다.

```java
int a = 10;

a++;
++a;
```

전위 증가:

```java
System.out.println(++a);
```

값을 먼저 증가시키고 사용한다.

후위 증가:

```java
System.out.println(a++);
```

값을 먼저 사용하고 나중에 증가시킨다.

예시:

```java
int a = 10;

a++;
++a;

System.out.println(++a); // 13
System.out.println(a++); // 13
System.out.println(a);   // 14
```

## 14. 논리 연산자와 단축 평가

논리 연산자는 조건식을 연결할 때 사용한다.

| 연산자 | 의미                     |
| ------ | ------------------------ |
| `&&`   | AND, 모두 참이면 true    |
| `\|\|` | OR, 하나라도 참이면 true |
| `&`    | AND, 양쪽 모두 검사      |
| `\|`   | OR, 양쪽 모두 검사       |

`&&`는 앞 조건이 `false`이면 뒤 조건을 실행하지 않는다.

```java
int a = 10;

System.out.println(a > 20 && ++a > 10);
System.out.println(a); // 10
```

`||`는 앞 조건이 `true`이면 뒤 조건을 실행하지 않는다.

```java
int a = 10;

System.out.println(a < 20 || ++a > 10);
System.out.println(a); // 10
```

`&`, `|`는 조건식에서 양쪽을 모두 평가한다.

```java
int a = 10;

System.out.println(a > 20 & ++a > 10);
System.out.println(a); // 11
```

실무에서 조건문은 보통 `&&`, `||`를 사용한다.  
`&`, `|`는 비트 연산이나 양쪽 조건을 반드시 평가해야 하는 경우에 사용한다.

## 15. 비트 연산자

비트 연산자는 정수를 2진수 단위로 계산한다.

```java
int read = 0b100;
int write = 0b010;

System.out.println(Integer.toBinaryString(read | write)); // 110
System.out.println(Integer.toBinaryString(read & write)); // 0
```

OR 연산:

```text
100
010
---
110
```

AND 연산:

```text
100
010
---
000
```

비트 연산은 권한 플래그처럼 여러 상태를 하나의 정수로 관리할 때 사용할 수 있다.

```java
int read = 0b100;
int write = 0b010;
int execute = 0b001;

int permission = read | write;
```

## 16. 삼항 연산자

삼항 연산자는 조건에 따라 다른 값을 선택할 때 사용한다.

```java
int score = 99;

String message = score >= 90 ? "합격" : "불합격";

System.out.println(message);
```

구조:

```java
조건식 ? 참일 때 값 : 거짓일 때 값
```

조건이 단순할 때는 삼항 연산자가 짧고 보기 좋다.  
조건이 길어지면 `if-else`로 풀어 쓰는 편이 낫다.

## 17. 이번 주에 헷갈렸던 부분

### Scanner 입력 버퍼

`nextInt()`는 숫자만 읽고 엔터는 남길 수 있다.  
그래서 바로 `nextLine()`을 사용하면 입력이 건너뛰어질 수 있다.

```java
int age = sc.nextInt();
sc.nextLine();
String name = sc.nextLine();
```

입력 방식이 섞일 때는 버퍼에 남은 엔터를 의식해야 한다.

---

### char 기본값

`char`의 기본값은 공백이 아니라 널 문자`'\u0000'`이다.

```java
static char ch;

System.out.println((int) ch); // 0
```

---

### 정수 나눗셈과 실수 나눗셈

정수에서 `0`으로 나누면 예외가 발생한다.

```java
System.out.println(10 / 0); // ArithmeticException
```

실수에서 `0.0`으로 나누면 예외가 아니라 `Infinity`나 `NaN`이 나올 수 있다.

```java
System.out.println(10.0 / 0.0); // Infinity
System.out.println(10.0 % 0.0); // NaN
```
