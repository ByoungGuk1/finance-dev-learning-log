## 잔고 반영

주문시 계좌의 예수금과 보유 수량을 즉시 갱신하여 다음 주문 검증에 반영

## DAG 기반 오케스트레이션

DAG : 방향성 비순환 그래프

의존성을 명확히 정의  
A가 끝나면 => B,C 동시 실행 => B,C 둘다 성공하면 => D 실행

ETL 워크플로우  
추출 => 가공/손익 계산 => 최종 원장

# 보험

## CFP

현금 흐름 방식

처음부터 이익까지 계산 (최신) - 시뮬레이션 방식

보험료 = 최적 가정 원가 + 목표이익

## 언더라이팅

보험사가 해당 고객의 리스크를 확인하고 해당 계약에 추가 조건을 걸어서 회사의 이득을 볼 수 있게 계약하는 진행 절차

### 리스크 확인 조건

#### 신체적

건강상태

#### 환경적

직업

#### 도덕적

가입 목적

#### 재정적

소득

### 수치 평가법

해당 절차의 결과  
점수가 높으면 회사 입장에서 불안한 요소

### 진행

해당 상황 진행 중 AI가 자동 심사과정도 있다 -> 결과 도출까지만 하고 최종 확정은 사람이

이유:  
데이터 불완전  
설명 가능성 부족  
예외 케이스 과다  
모델 편향

해당 데이터는 누적하며 업데이트 하지 않고 추가 데이터를 생성하여 저장

# 여신/수신

## 예대마진

수신으로 모은 돈을 여신으로 굴려 금리차로 남긴 돈

## 여신 종류

### 신용대출

신용점수, 소득, 재직, 기존 부채

### 주택담보대출

담보가치, LTV, DTI, DSR

### 전세자금대출

임대차계약, 보증기관 보증 가능 여부

### 마이너스통장

신용도, 소득, 약정한도, 사용금액
