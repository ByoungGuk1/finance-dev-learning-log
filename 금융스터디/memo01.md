# 핀테크

## 오픈뱅킹

다양한 은행을 하나의 어플리케이션을 이용하여 이용할 수 있게 하는 것

## 마이데이터

# 보험

보험료 -> 내는 돈  
보험금 -> 받는 돈

계약자 - 보험사와 계약을 맺고 돈을 내는 사람
피보험자 - 사건 또는 사고의 대상이 되는 인물이나 물건
수익자 - 사건 또는 사고 발생 후 보험금을 수령하는 인물

## 연금 -> 생명보험 류

### 정액보상

계약 시 받을 보험금를 정해두고 사건 발생 시 수령

중복 수령이 가능

### 실손보상

실제 손해액 만큼 보험금를 수령

중복 수령이 불가능
