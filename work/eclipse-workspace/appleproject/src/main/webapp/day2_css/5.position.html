2. relative — 자신의 원래 위치 기준으로 이동

원래 있던 자리를 기준으로 top · left · right · bottom만큼 이동합니다.
핵심: 원래 자리는 그대로 유지됩니다 — 주변 요소가 밀리지 않습니다.

부모에 position: relative 가 없으면 계속 위로 올라가 body까지 올라갑니다.

position이 static이 아닌 요소들 사이의 앞뒤 순서를 결정합니다.
숫자가 클수록 앞에 나옵니다. position 이 있어야 z-index가 동작합니다.

📋 position 속성 한눈에 비교

값 기준점 문서 흐름 주요 사용처
static 없음 (기본값) 유지 기본 상태
relative 자신의 원래 위치 유지 (빈 자리 남음) 미세 조정, absolute 기준 부모
absolute 가장 가까운 positioned 부모 이탈 (빈 자리 없음) 뱃지, 툴팁, 드롭다운
fixed 뷰포트 이탈 헤더, 맨위로 버튼, 채팅
sticky 스크롤 임계점 유지 헤더, 사이드바, 탭메뉴
