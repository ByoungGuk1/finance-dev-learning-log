1. block — 줄 바꿈, 너비 100%

block 요소는 항상 새 줄에서 시작하고 가로 너비 전체를 차지합니다.
대표 태그: div p h1~h6 ul li

2. inline — 줄 바꿈 없음, 내용만큼

inline 요소는 줄 바꿈 없이 옆으로 이어지고 내용만큼만 너비를 가집니다.
width · height가 적용되지 않습니다.
대표 태그: span a strong em

inline처럼 옆으로 이어지면서 width · height도 설정할 수 있습니다.

4. none — 완전히 숨김 (공간도 사라짐)

display: none 은 요소를 완전히 제거합니다 — 공간도 차지하지 않습니다.
visibility: hidden 은 안 보이지만 공간은 그대로 유지됩니다.
