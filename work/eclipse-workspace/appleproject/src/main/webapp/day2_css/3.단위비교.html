1. px — 고정값 (화면 픽셀)

브라우저 설정이나 부모 요소에 관계없이 항상 고정된 크기입니다.
사용자가 브라우저 글자 크기를 키워도 px은 반응하지 않습니다.

12px
16px
24px
32px

2. em — 부모 font-size 기준

부모 요소의 font-size를 1로 봅니다.
점선 박스 = 부모. font-size: 16px 을 20px 로 바꾸면 자식이 모두 커집니다.

부모 font-size: 16px (em 기준)
1em = 16px (부모와 동일)
1.5em = 24px
2em = 32px

⚠️ em 중첩 주의 — 모두 font-size: 1.5em 인데 안으로 갈수록 커집니다.

1.5em → 24px
1.5em → 36px (부모 24px × 1.5)
1.5em → 54px (부모 36px × 1.5)

3. rem — html font-size 기준 (실무 권장)

항상 html의 font-size를 1로 봅니다. 부모가 얼마든 상관없습니다.
html { font-size: 16px; } → 1rem = 16px 고정.
html 한 곳만 바꾸면 rem 단위 전체가 비례해서 바뀝니다. (TODO A 확인)

부모 font-size: 24px — 하지만 rem 자식은 무관합니다
0.75rem = 12px (html 16px × 0.75)
1rem = 16px (html 기준)
1.5rem = 24px
2rem = 32px

4. % — 부모 너비 기준

부모 요소의 width를 100%로 봅니다.
점선 박스 = 부모. 부모 width를 600px 으로 바꾸면 자식 % 기준이 달라집니다. (TODO C 확인)

부모 width: 100%
width: 25%
width: 50%
width: 75%
width: 100%
