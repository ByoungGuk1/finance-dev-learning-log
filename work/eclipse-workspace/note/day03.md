메모리 영역
메소드 영역, 힙 영역, 스택 영역

메소드 영역 - 바이트코드 파일을 읽은 내용이 저장

- 상수
- static
- 클래스 단위로 저장

스택 영역

- 메소드를 호출할 때 마다 생성되는 영역
- 함수 마다 생긴다고 생각

힙 영역

- 실행시 객체가 생성되는 영역
