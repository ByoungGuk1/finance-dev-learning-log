## class 시작

object를 만드는 틀 (template) 템플릿
object : class 를 이용해서 만든 독립된 개체

Car c1 = new Car()
class object = instance

- instance : 실체 (메모리에 할당된 실체화 된 부분)

### 객체지향 프로그래밍의 특징

- 캡슐화
  실제 구현 내용을 외부에 숨기는 것 -> 대표적으로 private로 접근 제어
- 상속
  자식객체가 부모객체의 필드와 메서드를 상속받아서 사용할 수 있게 하는 것
- 다형성
  사용방법은 동일하지만 실행 결과가 다양

---

스택 영역에는 참조 변수가 저장 -> 힙 영역에는 new로 생성한 객체가 저장 -> 참조 변수는 힙 객체를 가르킴
