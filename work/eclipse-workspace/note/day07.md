## 상속 (inheritance)

이미 개발된 클래스를 재사용하여 중복코드를 줄일 수 있다.

상속을 위한 키워드 `extends`

### 오버라이딩

부모에게 상속받은 메서드를 자식객체에서 수정하는 것

### super()

상속받으면 생성자에 super() 자동 생성
지워도 적용

### 다형성

사용법은 동일하지만 결과가 다양하게 나오는 성질

주의 : 변수는 업케스팅 되지 않고 하이딩 된다.
필드는 참조 변수 타입 기준으로 접근되고, 오버라이딩된 메서드는 실제 객체 타입 기준으로 실행된다.

즉 업캐스팅을 하면 메서드는 업캐스팅 된 메서드가, 필드의 값들엔 부모의 기존 값이 적용된다.
다운캐스팅을 진행한 후엔 자식 객체의 값이 참조된다.
다운캐스팅을 한 객체를 다시 업캐스팅하여도 동일하게 메서드는 오버라이딩 된 메서드가, 필드 값엔 기존 부모 클래스의 값이 적용된다.
