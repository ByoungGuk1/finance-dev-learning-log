## extention

### React / Redux / React Native

코드 템플릿을 단축어로 자동 생성해주는 도구

### TypeScript Importer

필요한 모듈을 자동으로 import 해주는 기능

### ESLint

“코드 품질 + 규칙 검사 도구”, import가 잘되었는지 검사

### Prettier- code formatter

코드 스타일을 자동으로 정렬해주는 포맷터

### React TypeScript Toolbox

개발 생산성을 높여주는 보조 도구 모음

### Path Intellisense

파일 경로를 자동완성해주는 기능 ( import경로입력시 자동으로 파일목록을 보여줌)

### Error Lens

에러·경고 메시지를 코드 줄 옆에 바로 표시해주는 도구

### Tailwind CSS IntelliSense

클래스 자동완성 + 문법 도움 + 유효성 검사를 제공하는 도구
